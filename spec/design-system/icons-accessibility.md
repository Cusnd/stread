# 图标、文案与可访问性

[设计系统](README.md) · [按钮](buttons.md) · [表单](forms.md)

## 图标的职责

图标用于识别重复出现的工具和操作方向。已有明确文字时，只有能提升辨识效率才增加图标；不要为了填满留白而加文件、上传或阅读装饰。

当前使用 [icons.jsx](../../prototypes/insight-composer/src/icons.jsx) 统一包装语义图标，[icon-style.js](../../prototypes/insight-composer/src/icon-style.js) 提供清线（Lucide，默认）、书卷（Iconoir）、墨印（Phosphor）三种选择。新图标从包装层导入，不在业务组件中绑定一种图标库。包装层默认 `size=20`，具体控件可能覆盖尺寸；以[按钮](buttons.md)中的触发区域为准，不能把图形尺寸当作点击范围。

| 场景 | 当前做法与后续规则 |
| --- | --- |
| 设置、关闭、搜索、侧栏开关等常见工具 | 保留图标；纯图标按钮提供准确的可访问名称 |
| Collection 详情中的资料类型与洞见数量 | 纯文字元数据；不重新增加装饰图标；列表行的模式化图标另按其既有规则处理 |
| Collection 的阅读按钮、阅读计划操作 | 使用文字表达动作和状态；计划操作保持低强调 |
| Queue 任务行 | 标题、任务编号和信息对齐；不恢复已移除的大文件图标及其占位 |
| Queue 源文件区域的“上传新文件” | 纯文字操作，与选择、搜索、更多文件组成一组 |
| 顶栏“添加资料 / 添加任务” | 当前保留小加号与文字；这是明确的入口，不意味着所有文字操作都要加图标 |
| 内容原图、语义批注色 | 保留来源信息，不按界面极简策略删除或改色 |

实现参照：[WorkspaceHeader](../../prototypes/insight-composer/src/workspace/WorkspaceHeader.jsx)、[MaterialDetails](../../prototypes/insight-composer/src/workspace/MaterialDetails.jsx)、[QueuePage](../../prototypes/insight-composer/src/workspace/QueuePage.jsx)、[QueueTaskDialog](../../prototypes/insight-composer/src/workspace/QueueTaskDialog.jsx)。

[interface-mode.js](../../prototypes/insight-composer/src/interface-mode.js) 当前默认 `minimal`，可切到 `normal`。模式选择不能代替对具体图标职责的判断，也不能隐藏关闭、展开、返回等必要操作。新增装饰需同时核对两种模式。

## 文案和信息密度

- 按钮写动作：添加任务、加入队列、继续阅读、复制给 Agent。避免用解释性长句撑大按钮。
- 使用对齐、分组和留白表达关系；不要在明确的字段标题下再写同义说明。
- 保留有用的限制、错误原因、冲突处理和下一步操作。简洁不等于删掉用户作决定所需的信息。
- 操作反馈用准确的已发生事实。保存请求、加入 Queue 和复制内容都不表示 Agent 已开始执行。
- 任务编号是可复制的稳定引用，保留等宽及不换行处理；正文内部 ID 不作为默认展示标题。
- 标题优先使用可用宽度，自然换行；不要为模仿截图给短标题设置过小宽度。状态短词在自身控件内保持完整，不能一个字一行。

## 交互必须可用

以下是共用验收约束，不是对全部既有控件的自动合格声明：

| 对象 | 必须保留 |
| --- | --- |
| 导航链接与动作按钮 | 链接保留导航语义；按钮保留键盘激活；不要以不可聚焦的文字模拟操作 |
| 纯图标按钮 | `aria-label` 或等效可访问名称；装饰性 SVG 不重复播报 |
| 当前页、开关、单选和展开 | 分别提供对应的 current / checked / pressed / expanded 状态；不只依靠颜色 |
| 表单字段 | 可访问名称、错误关联和准确点击范围；Queue 的 `TaskField` 不把整块空白变成输入点击区 |
| 弹窗 | 焦点进入、约束在当前层、Esc 和关闭入口、退出后返回合理位置；关闭中的控件不可操作 |
| 可点击内容行 | 鼠标与键盘均可操作；行内复制等动作独立，拖选文本不触发行操作 |
| 背景与滚动 | 模态层期间按需锁定；关闭后恢复；局部滚动不带走无关面板 |

聚焦样式必须清晰但克制。共享按钮和选择卡使用中性灰 `--ui-focus-ring` 与浅色 `--ui-focus-halo`；普通字段与 ReaderSelect 使用 `--ui-field-focus-border` 的柔和边框和 `--ui-field-focus-halo` 的 3px 光晕，保持白底与原有形状。焦点状态优先于悬停，不能让 hover 覆盖键盘反馈；强制颜色模式保留系统焦点轮廓。图标风格、色板预置、界面模式和快捷键录入不使用白底深色描边：普通操作用浅灰，持续选中用较深灰并保留原生 checked / pressed 语义或勾选标记。规则见[按钮](buttons.md)和[表单](forms.md)。

2026-10-30 的控件浏览器验证覆盖三档缩放、选择卡状态、键盘焦点代理与强制颜色；导航验证覆盖窄窗模态导航、焦点返回和真实文本拖选。颜色与可见文字共同表达状态，不以删掉焦点或缩小命中区换取简洁。

## 核对方式

修改图标或文案后检查三种图标风格、两种界面模式及长文本；修改交互后用 Tab、Shift+Tab、Enter、空格、方向键和 Esc 检查适用控件。实际拖选标题与正文，确认复制和阅读操作不互相触发。缩放、减少动态效果与高对比环境应按改动范围检查，不通过隐藏焦点或禁用原生选区解决视觉问题。
