# 阅读内容与应用界面的边界

[设计系统](README.md) · [视觉基础](foundations.md) · [导航与布局](navigation-layout.md)

Reader 与工作区共用界面控件、语义颜色、设置和动效。阅读正文有自己的排版系统；不能为了让它与列表控件“大小一样”，改变论文内容的字号、结构和原始语义。

## 当前排版职责

| 层 | 统一什么 | 允许什么差异 |
| --- | --- | --- |
| 应用界面 | 工具栏、菜单、表单、弹窗与焦点反馈 | 由明确的操作角色决定控件密度 |
| 正文与语言变体 | 同一语言、同一角色的字体、字号和段落留白 | 中英文与代码字体不同，标题及数学上下标有语义层级 |
| 普通图表与语义 HTML | 表格基础样式、题注、对象工具、局部滚动 | 原稿需要的表头、跨度、相对列宽、布局分组 |
| 用户对象偏好 | 默认跟随正文，可按对象调整文字大小 | 用户明确设置的对象字号，仅影响该对象及题注 |
| 来源内容 | 原文、译文、图像、数据、引用和稳定身份 | 原图的语义色、真实强调，不被 UI 主题抹去 |

当前 [reader-shared.css](../../prototypes/insight-composer/src/reader-shared.css) 让普通表格与 HTML 表格共享基础规则，`--reader-object-text`、`--reader-caption-text` 默认取 `--reading-size`。中文图表文字使用 Noto Serif SC / SimSun，英文使用 Georgia / Times New Roman，代码使用等宽字体。

内容布局间距使用 `--reader-space-1: .3em`、`--reader-space-2: .65em`、`--reader-space-3: 1.1em`。这些是阅读内容间距，不是按钮间距刻度。界面缩放与阅读字号也分别管理，见[视觉基础](foundations.md)。

## 复用规则

- 普通表格和 HTML 表格的同一视觉角色应一致，不按某篇论文、标题或表号增加例外 CSS。
- 自然语言先在可用宽度中换行；无法合理换行的数学和宽结构在对象内滚动。扩大对象宽度或打开 PDF 不应偷偷缩小内容字号。
- 对照视图使用已保存的源文、译文及对应关系。切语言是显示选择，不现场生成翻译，也不改变块或引用身份。
- 展开对象、引用回跳、原页联动应使用既有阅读器交互。作者内容不另写按钮和动画。
- 提高显示密度不得合并不同批注的身份、来源顺序、颜色及操作，也不得隐藏原文必要内容。

内容端允许的布局能力及 CSS 限制只在[统一样式](../统一样式.md)、[内容模块与布局](../内容模块与布局.md)与[作者指南](../../services/workspace/authoring-guide.md)维护。修改这些能力时同步对应文档，本页保留边界和入口，避免复制整份合同导致漂移。

## 核对方式

用普通表格和 HTML 表格并排检查相同角色；再检查中英文、对照模式、普通与较大阅读字号、打开 PDF 后的窄正文区、对象展开和局部滚动。必须能到达全部内容与操作，原生选区和引用返回不失效。

界面一致性检查不代替转换内容验收。全文与译文完整性、独立源文件复审、真实 Reader 检查及最新冻结哈希仍遵循[转换工作流](../../services/workspace/conversion-workflow.md)。
