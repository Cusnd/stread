# 首页阅读面板设计

2026-10-22：独立首页已退役。应用默认进入 Collection，名称保持 Collection；本文与对应交互稿仅保留为历史设计参考，当前页面组织见 [页面组织与阅读体验](页面组织与阅读体验.md)。

本页记录 2026-10-18 制作的首页交互设计稿。它承接当前阅读器与 Collection 的浅色、紧凑视觉语言。设计稿使用八份示例资料，本轮不代表生产首页、资料同步或真实阅读器接入已经完成。

## 页面职责

首页帮助用户接着读，并安排后续阅读顺序。上方呈现当前阅读资料与其他在读内容，下方切换未读和已读资料，阅读计划保持独立。分类树、标签管理和资料收纳由 [Collection](Collection页面设计.md) 承担。

当前阅读是一份明确选中的在读资料。示例默认选择“偏好优化：从问题到方法”，显示已有的第 3 节位置与阅读问题。没有访问时间或阅读遥测，因此不称为“最近阅读”，也不显示时长、连续天数或百分比。

## 布局与视觉

顶栏高 56px，保留阅读面板名称、首页状态和 Collection 入口。主内容分为阅读区域与约 300px 的计划栏，以细线区分。当前标题采用约 20px 衬线字体，其他资料使用约 13–14px 标题与至少 11px 的次级信息。

背景沿用 `#fafaf8`，正文为 `#24282d`，次级文字为 `#646b73`，边线为 `#e0e3e5`，强调色为 `#42658a`，选中底色为 `#e8edf2`。不增加封面拼贴、统计卡片、装饰图表或宣传文案。图标来自现有 Phosphor 图标库。

桌面左侧依次显示继续阅读和未读／已读资料，右侧显示计划。窄屏依次显示继续阅读、阅读计划、未读／已读资料，计划只渲染一次。窄屏顶部提供直达计划入口，避免计划被长列表推远。

## 阅读情况

所有计数由同一组资料派生。初始为 3 份在读、4 份未读、1 份已读。未读／已读切换仅影响下方清单，不改变当前阅读或计划。

查看标题或计划条目打开同一个示例节选预览，不隐式改变阅读状态。显式开始、重新阅读、标为已读或标为未读可以改变本地示例状态。当前资料离开在读状态后，首页采用另一份有效的在读资料；没有在读资料时显示空状态。

## 阅读计划

计划是有序且不重复的资料 ID 序列。初始顺序为偏好优化、奖励建模综述、强化学习导论、古希腊哲学。它独立于资料的阅读状态，也不把第一项自动视为当前阅读。

添加资料后追加到计划末尾。调整顺序显示上移、下移和移出动作，首项上移和末项下移禁用。标为已读不会自动移出计划。空计划仍保留添加入口。

## 节选与返回

节选预览明确标识为示例。打开后固定当前资料，即使背景计数或清单改变也不换篇。Escape 与关闭按钮返回首页，并保留清单筛选、计划顺序和页面位置。焦点回到原入口；入口因状态变化消失时，转到同一资料的新入口或稳定的区域控件。
