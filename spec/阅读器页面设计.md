# 阅读器页面设计

> 本页保留产品约定及带日期的设计背景。早期研究稿、截图和个人待办不随公共源码发布；历史验证描述不代表当前发布包的验收结果。当前范围以根目录 AGENTS.md、现行服务合同及本仓库代码为准。

2026-10-17：整理本轮已确认的阅读器方向。本文定义页面职责、布局和阅读连续性；设置、洞见和外部协作分别在关联 spec 中说明。2026-10-18 已有可交互阅读原型与本地术语表 MCP 读取；文章、洞见和云端协作仍未接入。用户最新确认界面应更小巧精致，现有批注保留。

## 页面目的与范围

阅读器用于专注阅读具体资料、查看原页、留下和回顾自己的洞见。阅读时的 AI 讨论在 ChatGPT 中进行，ChatGPT 通过工作台 MCP 读取资料，并按用户指令纠错、补充正文或保存洞见。

当前方案取消内置 AI 聊天、AI 边栏、AI 独立面板和顶栏 AI 入口。洞见保存用户主动留下的问题、批注和笔记，不承担聊天会话管理。上传文件通过 MCP 转换工具形成阅读器和 MCP 可使用的结构化内容，见 [文档转换](文档转换.md)。

不设计独立正文编辑器。用户在 ChatGPT 中提出纠错或补充，由 MCP 修改转换结果；工作台最多提供具体变更的预览与批准，规则见 [MCP 文档修订](MCP文档修订.md)。这不影响用户手动维护自己的问题、批注和笔记。

## 页面布局

| 区域 | 已确定的职责与行为 |
| --- | --- |
| 顶栏 | 提供返回 Collection、当前文章识别，以及“原页”“洞见”“术语”“阅读设置”等阅读操作入口。持久的阅读操作按钮集中在顶栏。 |
| 左侧目录 | 支持临时展开和固定显示，也可收起；按用户选择使用，不只提供一种展开方式。 |
| 正文 | 以文章本身为主，保留舒适行宽和留白。字体、字号等排版由用户调整。 |
| 正文旁的边注 | 按原文位置展示已保存的洞见，是可选显示方式；支持一键整体隐藏。 |
| 右侧工具区 | 用于原页对照、洞见边栏或术语表，正文和工具内容可对照查看。 |
| 临时居中面板 | 阅读设置和洞见均可按明确操作打开，关闭后回到阅读。洞见另保留右侧边栏形态。 |

正文段落不放置常驻操作按钮、悬浮操作条或“向 AI 提问”入口。2026-10-18 用户明确要求补齐宽表展开：图片、表格和 HTML 对象在编号/标签行右侧保留轻量“展开查看/收起”按钮，不另占一整条正文工具栏。原文内容、正常链接、可选高亮和已启用的边注仍可显示；已打开的设置或洞见内部可以包含完成相应任务所需的控件。

## 图表原位展开与手动大小

2026-10-18 最新反馈替代此前的独立全页查看：图表留在文章原位，左边缘固定，只向右利用阅读区域中的空白。前后段落、目录、顶栏继续可见，普通正文的宽度不随图表改变。可用宽度扣除页面安全边距及已打开的工具区；窄屏不能把整个页面撑出横向滚动。

2026-10-21：图片、标准表格和 HTML 对象共用同一尺寸控件。编号行提供「大小」和「展开查看/收起」。「大小」面板中，宽度通过百分比滑杆、数值输入和加减按钮调整，100% 表示该对象的默认宽度；范围按当前可用空间计算。右下角仍可拖动调宽，方向键每步 20px，Shift 每步 80px，Home/End 到达边界。最小宽度取 160px、默认宽度与当前可用宽度的最小值。图片保持长宽比；超宽表格局部横向滚动，纵向沿页面展开。

每个对象的内容字号默认跟随正文；手动调整后使用自己的 12–32px 字号，独立于宽度和其他对象。可以重新启用「跟随正文」；「恢复默认」同时重置当前对象的宽度和字号。图片的字号控制作用于图注及可选的图中文字转录，图片内部文字随图片整体缩放。宽度调整本身不缩放字体，所有内容和双语身份保持同一 DOM。

展开默认使用当前对象左边缘到阅读区域右边界的可用空间，最大为默认宽度的四倍；收起回到展开前的手动宽度或默认宽度。宽度比例和可选字号按文档及稳定 block ID 保存到工作台 SQLite 服务端，样本入口和资料库使用相同文档身份。旧浏览器设置只在服务端没有该对象记录时迁移；恢复默认保留明确的空值记录，避免旧设置再次覆盖。同一工作台的其他浏览器或设备可读取这些偏好，打开的页面每五秒及恢复焦点时同步。窗口变窄只限制实际宽度，不覆盖保存的比例。保存失败显示待同步和重试入口；展开仍是临时状态，不改写文档 revision、双语身份或洞见引用。

边注列仍保留布局占位。只有与扩宽对象覆盖区域相交的批注暂时淡出并停止接收点击和键盘焦点；对象收回后淡入。未被覆盖的批注继续显示，用户的“显示边注”偏好不被改写。边注列的空白部分不能挡住图表控件。关闭洞见工具后，按原偏好及当前遮挡关系恢复边注。

展开/收起使用 320ms 宽度缓动，反向操作从当前宽度连续衔接；不复制 DOM、不使用整表 transform 缩放。拖动时直接跟随指针，松开后记住尺寸。批注淡出约 100ms、淡入约 160ms；系统要求减少动态效果时直接切换。收起恢复展开前的表内横向位置，焦点留在实际操作控件；重置后把焦点交还可用的尺寸控件。

源/译/对照、选择、洞见保存、编辑和回跳继续使用同一对象及引用流程。未保存草稿保留原 textarea、内容和光标；窄单元格不能把输入框压成同样的窄条。其他正文块一直存在，可直接导航或回跳，无需先退出一个独立视图。

对象尺寸按文档和稳定块身份保存在本地服务；独立公式展开仍属后续工作。

## 目录、原页与洞见的配合

2026-10-26：目录优先使用真实章节标题；没有标题时可以显示 Agent 单独提供的「阅读导航」。两者都为空时释放空栏宽度，保持保存的固定/收起偏好，详见 [辅助阅读导航](辅助阅读导航.md)。

- 目录具有收起、临时展开和固定显示三种状态。临时目录用于快速导航，固定目录用于持续查看文章结构。
- 原页用于核对原文件中的版式、公式、表格和图片。PDF 与正文支持双向滚动联动、点击区域跳回正文及明确定位原页；可关闭自动联动，操作中的一侧驱动同步，完整规则见 [阅读与 PDF 双向同步](阅读与PDF双向同步.md)。
- 桌面右侧工具区一次展示原页、洞见边栏或术语表。打开占用正文旁空间的工具时，暂时收起边注，避免同一内容重复占位；关闭工具后按原有边注显示偏好恢复。
- 洞见边栏和居中面板是同一份内容的两种形态，切换规则见 [洞见与问题合集](洞见与问题合集.md)。
- 窗口较窄时优先保证正文可读。目录固定显示的降级方式、工具区最小宽度和切换阈值需要在原型中验证，不沿用参考项目的断点作为本项目已定数值。

## 阅读连续性

正文支持原文、译文和双语对照，规则见 [双语对照](双语对照.md)。这里的语言对照与核对原文件版式的“原页”是不同能力。切换语言不复制正文块，不改变洞见原本引用的语言；语言设置集中管理，具体布局与快捷操作待原型验证。

切换目录状态、打开或关闭工具、调整排版时，应保持正在阅读的内容位置，避免仅保留滚动像素而跳到另一段。查看原文引用或洞见关联位置后，应能返回此前阅读位置。

关闭后重新打开资料，需要恢复阅读位置、设置和已保存的洞见。阅读位置的存储粒度、恢复提示、跨设备偏好和多窗口处理由相关 todo 细化。

MCP 修订后刷新为新版本，仍存在的块保留阅读位置；用户补充在正文中有来源标识，没有对应 PDF 区域时明确说明。正文重排、双语切换与 PDF 联动共同使用块身份，避免来回抢位置。

## 视觉方向与设计参考

当前阅读器采用用户确认的浅中性目录、近白正文、深灰文字和克制的蓝灰动作色。目录、顶栏与面板保持紧凑，选中层级用细线、轻背景和文字颜色表达；保留现有批注与输入框的字号、尺寸及交互。早期 [Collection 工作台](Collection页面设计.md) 的深色导航不再是阅读器当前的视觉目标。正文排版与界面字体独立设置；设计图中的宋体、字号、行距、宽度和文案均不直接成为固定默认值。

早期静态设计图与参考项目未随公共源码发布。当前界面行为以本文的有效约定及实际代码为准，参考图中的旧 Agent 入口不属于当前产品。
