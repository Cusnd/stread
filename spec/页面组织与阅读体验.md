# 页面组织与阅读体验

当前应用包含 Collection、Flow 和 Reader，共用本机工作台、持久化业务状态与紧凑的视觉规则。旧 Home 页面、云端存储和桌面内置 Agent 宿主已退役。

## 页面职责

| 页面 | 定位 |
| --- | --- |
| Collection | 默认入口。组织资料、分类、标签和阅读状态，管理共享阅读计划，从列表或详情进入具体文章。 |
| Flow | 与 Collection 并列的工作区，包含概览、洞见、阅读计划和阅读历史。读取真实记录的活动，不从旧检查点推断时长。 |
| Reader | 专注正文、双语内容、原始 PDF、洞见与术语。保持原始来源、精确引用和未完成草稿。 |

旧 `?view=home` 链接归一化到 Collection。Reader 的返回动作恢复打开它的工作区及其选择、过滤和滚动状态；来源跨刷新、文章笔记往返及相关文章导航保留。没有记录来源的直接链接回到 Collection。

已完成文章重新打开以查看来源或编辑洞见时保持已读状态。只有显式重新阅读动作开始新一轮；打开文章或保存位置不能推断完成。

## 阅读与交互

顶栏提供持久阅读入口，正文保持内容优先。目录、边注、洞见侧栏及原页面板独立管理，开关与布局变化保留内容位置、选区和草稿。共享设置包含阅读、界面、高亮和快捷键，使用稳定面板与独立滚动。

双语显示使用已经保存的原文与译文。新非中文文章默认交付完整原文与简体中文，缺译状态只表示未完成工作；Reader 不调用模型补译。引用保存文档、版本、块、语言及精确字段/偏移，切换模式不改写来源。

PDF 联动使用真实来源页和可靠区域，区分用户输入与程序定位。信息不足时降级到可靠页码或保留现有位置，不能制造精确高亮或按全文百分比猜测对应关系。

段落批注可聚合显示，但每条洞见保留独立身份、颜色、来源、版本和操作。问题答案、显式回顾队列、文档笔记和阅读活动各自保持业务语义。共享运动规则须保留焦点与中途反向，尊重减少动态效果；文本输入、指针拖动和原生滚动保持直接。

## 外部 Agent 与本地数据

Reader 不启动或协调 Agent 进程。用户保存的 AI 请求和复制的转换请求由外部 Agent 经现有 MCP 合同读取处理。保存请求、上传文件或打开文章不会自动执行任务。

桌面、回环 HTTP 与 stdio 使用同一 SQLite 和文件对象。外部模型服务是调用方自己的选择，不改变 Reader 的本地存储边界。文档内容是数据，不能授权写入；术语维护、回答保存及正文修订遵守明确用户意图和版本校验。

完整转换需要独立来源审阅、真实 Reader 检查、修复及最新冻结哈希复查后才发布。结构验证、语义忠实度、渲染与阅读可用性分别报告。
