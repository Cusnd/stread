# 阅读设置与快捷键

> 本页保留产品约定及带日期的设计背景。早期研究稿、截图和个人待办不随公共源码发布；历史验证描述不代表当前发布包的验收结果。当前范围以根目录 AGENTS.md、现行服务合同及本仓库代码为准。

2026-10-17：已确定使用集中式阅读设置，并把快捷键动作与顶栏按钮的点击偏好分别管理。本文记录交互要求；候选键位和示意图中的参数仍需验证。

## 设置入口与阅读环境

阅读设置采用可临时打开的居中面板，支持快捷键打开，也支持点击顶栏“阅读设置”。阅读操作的持久入口集中在顶栏，正文区域保持纯净。

设置用于集中调整阅读呈现。调整后应能直接观察效果，关闭后继续当前阅读；偏好保存的作用范围、默认值和跨设备行为见待定项。

## 设置内容

| 设置组 | 当前确定的范围 |
| --- | --- |
| 界面大小 | 用户可调目录、顶栏、按钮和面板的大小；当前紧凑版为 80%，标准为 100%，较大为 120%，正文和批注独立。 |
| 显示 | 控制正文旁边注的显示或隐藏；选择目录收起、临时展开或固定显示。 |
| 排版 | 正文字号 14–24px，未单独设置的表格、代码、算法文字和图表题注默认跟随。每个对象旁的「大小」面板可独立设置 12–32px 字号或恢复跟随，详见 [统一样式](统一样式.md)。正文宽度按可用页宽的 50%–100% 调整，保留边注空间。 |
| 语言与对照 | 支持原文、选定语言的译文与双语对照，选择目标译文语言与两种文字的先后顺序；数据和缺译行为见 [双语对照](双语对照.md)。 |
| 原页联动 | 控制正文与 PDF 原页是否自动双向跟随；关闭后保留明确定位能力，行为见 [阅读与 PDF 双向同步](阅读与PDF双向同步.md)。 |
| 交互 | 配置顶栏“洞见”按钮的点击结果：打开边栏或打开居中面板。 |
| 高亮颜色 | 选择预置色系，并勾选显示在洞见录入色盘中的颜色；至少保留一种。 |

“正文高亮”开关、浅色／深色／跟随系统，以及“记住洞见上次打开方式”已在讨论或设计图中提出，属于待细化选项；具体采用范围不因图片中存在控件而视为完成定稿。

### 界面大小

2026-10-18：用户要求 UI 大小可自行调整，并明确当前紧凑版为 80%。原型在「阅读设置 → 阅读」中提供 80%–120% 滑块，每步 5%；默认值和重置值均为 80%。以已确认的紧凑尺寸为基准，100% 对应其 1.25 倍，120% 对应其 1.5 倍。目录、顶栏及面板控件随之变化；正文仍由正文字号设置控制，已确认的批注、输入框及类型短栏保持原尺寸。

调整即时影响阅读器界面，当前打开的设置面板保持稳定，避免拖动时滑块自身移动；再次打开设置面板时使用新尺寸。选择保存在当前浏览器同一站点的本地设置中，并在同源窗口间同步；尚未同步到账号或其他设备。窄屏面板受可用窗口尺寸约束，内容可滚动，关闭和「完成」操作保持可达。

### 正文宽度与字号

2026-10-21：每个图表/图片的独立宽度、字号和「跟随正文」状态已接入服务端保存，按文档与稳定 block ID 共享。原有浏览器设置会迁移到服务端尚无记录的对象；明确的恢复默认同样持久化。对象大小面板显示保存或重试状态。同一工作台的不同浏览器可以共享这些对象偏好；下述正文字号、整体正文宽度和界面大小继续使用各自的浏览器偏好。

2026-10-18：用户明确否定固定像素的正文宽度控制，要求用页宽百分比，并扩大可调上限。在「阅读设置 → 阅读」中使用 50%–100% 的正文宽度滑杆，每步 5 个百分点，默认与重置为 80%。此前 680–860px 的方案由此替代。

百分比以实时可用正文空间为基准：先扣除目录、打开的工具侧栏、页面内边距，以及开启时的边注栏与间距，再乘以所选比例。100% 用满剩余空间，不设固定像素上限；同一比例随窗口缩放、目录或侧栏开合自动重新计算。边注栏保持既有响应式宽度，不因加宽正文而自动隐藏或挤窄。隐藏边注时，其空间重新参与正文宽度计算。640px 及以下窗口使用完整正文区，避免按桌面比例压窄手机正文；比例偏好仍保留，回到桌面后恢复。图表的原位展开和单独调整宽度保持独立。

旧版像素宽度不直接换算成百分比，迁移后采用 80%，同时保留原字号。

最小正文字号从 17px 降到 14px，上限仍为 24px，默认 20px。字号和宽度独立，保存于当前浏览器同源本地设置，刷新后保留，并同步同源标签页；账号及跨设备同步未实现。界面大小、边注字级和输入框字级保持各自规则。

### 高亮色系与可选颜色

设置面板采用「阅读 / 高亮」分页，避免把色系和日常阅读选项堆成长列表。阅读页提供实时字号预览、边注开关及洞见打开方式；高亮页用配色条比较预设，用圆形色样启用或隐藏颜色，并在文章文字上预览。面板开合、分页与内容高度、选色和开关均使用短过渡；关闭时先停止交互，再完成退场，减少动态效果模式直接切换。

2026-10-18：用户要求在设置中选择可用的高亮颜色，并预置包括马卡龙在内的几个色系。当前原型提供经典柔彩（原四色）、马卡龙（六色）、大地色（五色）和冷雾色（五色）；每组展示颜色预览，可单独勾选色盘中显示的颜色，也可一键全部显示。

色系与各自勾选结果保存在当前浏览器、同一站点的本地设置中；切换色系后再切回来，保留该组的选择。现有洞见与正在编辑的草稿继续使用原颜色，不随预设映射变化。若当前颜色不在启用列表，色盘将它作为带分隔的“当前颜色”保留；新建洞见则使用已启用颜色，优先沿用仍可选的上次使用颜色。

这些设置不涉及洞见内容的持久化，也尚未同步到账号或其他设备。

## 快捷键和点击行为

已确定的是不同操作可以直接到达不同结果：

- 阅读设置有独立打开动作。
- 边注有一键显示／隐藏动作，隐藏只影响呈现，不删除内容，也不留下正文占位控件。
- 洞见边栏与洞见面板使用不同快捷键，分别打开或收起对应形态。
- 顶栏“洞见”按钮根据阅读设置中的偏好执行；调整点击偏好不改变快捷键各自对应的动作。
- 单字母快捷键在输入框、笔记编辑器或输入法组字期间不触发。面板关闭后恢复合理的焦点与阅读位置。

下表保留讨论时的键位候选，供后续原型验证，不作为已经确认的最终键位：

| 动作 | 候选键位 |
| --- | --- |
| 打开阅读设置 | `Ctrl + ,` |
| 显示／隐藏边注 | `B` |
| 打开／收起洞见边栏 | `I` |
| 打开／关闭洞见面板 | `Shift + I` |
| 关闭当前临时面板或返回阅读 | `Esc` |

## 待细化与验证

- 字体来源、行距范围，以及已确定字号和宽度之外的排版偏好。
- 字号、宽度、界面大小和色系已采用同源浏览器偏好；其他设置是否按文档覆盖，以及账号和设备间同步继续细化。
- “洞见按钮点击行为”的默认值，以及是否提供“记住上次”。
- 最终快捷键及其浏览器、操作系统、输入法和无障碍操作冲突。
- 边注和高亮的独立显示关系，以及窄窗口下的呈现方式。
- 双语采用上下排列还是并列、不同窗口下的呈现，以及语言切换入口与快捷键；切换不能丢失阅读位置或改动批注原本引用的语言。
- PDF 联动开关的最终默认值、偏好作用范围和顶栏快捷入口；验证关停自动跟随与明确定位互不混淆。

布局约束见 [阅读器页面设计](阅读器页面设计.md)，洞见形态见 [洞见与问题合集](洞见与问题合集.md)，实施事项见 页面组织与阅读体验待办。

## 2026-10-21：可自行修改的快捷键

设置沿用居中面板，在「阅读」「高亮」旁增加「快捷键」。每个动作显示当前键位与用途；点击键位进入录制，直接按新组合后即时保存。冲突提示指出占用动作，不覆盖原键位；录制时 Esc 取消（录制关闭动作时可设为 Esc），Tab 退出录制并继续移动焦点，Delete / Backspace 停用。提供单项恢复、全部恢复；单项恢复有冲突时同样解释原因。

| 动作 | 默认键位 |
| --- | --- |
| 阅读设置 | Ctrl / ⌘ + , |
| 添加洞见（已有选区） | A |
| 请求更改 | R |
| 洞见边栏 | I |
| 洞见面板 | Shift + I |
| 显示 / 隐藏边注 | B |
| 保存洞见或更改请求 | Ctrl / ⌘ + Enter |
| 关闭当前菜单、输入框或面板 | Esc |

键位存储于本机浏览器，同源标签页同步。阅读动作在输入框、可编辑区域、中文组字或弹出菜单中暂停；保存、关闭和设置使用其明确的输入上下文。避免占用常见浏览器和文字编辑快捷键，Tab / Enter / 方向键继续负责界面导航。顶栏提示同步显示修改后的键位。

「请求更改」只有快捷键创建入口，不增加顶栏按钮或选区按钮。有选区时直接携带位置；无选区时可选择文字、点击段落或图表内容，也可直接提出全文修改要求。复用现有输入框与类型菜单，选择「内容纠错」「译文修改」「其他要求」。请求单独存储，在洞见的「全部」视图下查看、编辑、撤回和恢复；R 编号可复制给 AI。保存请求不等于 AI 已执行修改，实际处理沿用 [MCP 文档修订](MCP文档修订.md)。
