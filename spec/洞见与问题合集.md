## 内容组织

洞见按当前文章组织，顶栏原先的“边注”入口改为“洞见”，独立的“笔记”入口并入其中。

| 内容 | 职责 |
| --- | --- |
| 问题合集 | 保存用户主动提出并决定保留的问题，供后续回看、补充和跟进。每篇文章有自己的合集。 |
| 批注 | 保存针对段落、句子、公式、图片或其他原文位置的注释，可定位回对应内容。 |
| 文档笔记 | 保存对整篇文章的总结、想法和较长的思考，可按需要关联一个或多个原文位置。 |

用户明确选择保存的 ChatGPT 解释可以成为批注、文档笔记或已有问题的补充。存入哪类内容、关联哪篇文章与哪个位置，应由保存动作明确表达。

## 洞见录入的类型选择

2026-10-23：选区工具只保留「添加洞见」，移除独立的「仅高亮」入口。仍允许通过批注类型留空保存纯高亮。纯高亮是已定位到原文的批注，使用现有内部 ID、原文／译文身份、选区、颜色和 N 编号，不增加另一套来源或编号。问题和笔记仍需文字。

纯高亮在洞见列表中显示为「高亮」，保留摘录、回到原文和「补充批注」操作；正文旁不生成空白边注卡片。补写文字后同一条记录显示为批注，来源、颜色、内部 ID 和引用编号不变。清空批注内容并保存可回到纯高亮状态。高亮沿用现有当前标签页会话存储边界，尚未接入正式 MCP 持久化。

2026-10-18：用户选择 B「横向短栏」，确认位置与动画后授权应用到主阅读原型。

入口只显示当前类型的图标，去掉常驻类型文字和下拉箭头；展开后以一行显示“批注 / 问题 / 笔记”，保留图标、文字和明确的选中状态。选择栏置于整个输入框上方，与输入框左边缘对齐，间距 8px。滚动、窄屏和多行展开时保持这层关系，并避开顶部导航。

选择栏以短暂淡入、轻微位移和缩放展开，关闭时反向淡出，切换类型时图标平滑交替；减少动态效果模式直接切换。选择后保留正文、来源、光标所在输入区和既有引用编号规则。Esc 先关闭选择栏并返回图标入口，再次关闭输入框仍使用原有行为。

整体输入框延续已选 A 布局：单行横排，第二视觉行起展开为全宽正文，类型、颜色、保存和取消聚在左上方；最多显示五个完整文字行。类型选择的 B 决策不改变这一结构。

## 问题由用户主动添加

普通阅读行为和 ChatGPT 对话不自动产生问题条目。用户可以在阅读器中主动新建问题，也可以明确指示 ChatGPT 通过 MCP 添加；后一种方式同样属于用户主动添加。

例如，“解释这个公式”是讨论请求；“把奖励是否唯一加入这篇文章的问题合集”才是新增问题的请求。保存为普通批注或文档笔记不自动新增问题。对于已有问题，用户批准 Agent 将回答写入该问题，表示认可这份回答；成功保存后直接视为已解决，不再增加一次接受或解决确认。写入失败时不更新解决状态。

问题可以针对具体原文位置，也可以针对整篇文章；不要求用户为文章级问题指定一个虚假的段落锚点。用户批准回答保存即为对应解决状态的授权。未保存回答的问题显示待回答，已批准且成功保存回答的问题显示已解决。编辑和删除使用下述统一交互，排序另行细化。

## 问题详情与编号

点击原文旁的问题块，直接弹出居中的问题详情面板，显示问题编号、完整问题及详细回答。无需先进入洞见列表或再点一次“查看回答”。长回答在面板内滚动，公式保持可读；关闭后保留原文阅读位置并把焦点交还给打开面板的问题块。洞见列表中的同一问题也打开这份详情。

编号采用类型前缀加递增数字，支持一键复制，便于直接交给 AI：问题使用 `#Q00001`、`#Q00002`；批注和笔记共用 `#N00001`、`#N00002`。Q、N 两组独立递增，数字至少五位、不足补零，超过五位继续增长，不截断或循环。编号在工作台内唯一，不按文章重新计数，也不随排序、筛选或文字编辑变化。正式服务通过原子计数与唯一约束分配，删除后不回收编号。内部仍保留独立稳定 ID，编号映射到内容及其文章、版本与原文位置。

在问题与批注／笔记之间转换类型时，为同一内部 ID 分配对应系列的编号，保留原编号作为别名；切回原类型系列时恢复原编号。已经交给 AI 的旧编号仍应解析到同一条内容。未收到回答时，问题详情仍可打开并显示原问题和待回答状态。

### 编号的统一显示

Q、N 编号在原文边注、洞见列表和问题详情中使用同一套文字样式。类型标签（问题、批注、笔记）与编号分别呈现，以明确间距分隔；不把 Q 编号直接拼进普通类型文字，也不单独加粗 N 编号。

| 项目 | 已确认规范 |
| --- | --- |
| 字体 | 等宽字体，共用 `ui-monospace, "Cascadia Code", Consolas, monospace` 字体栈。 |
| 字号与字重 | `12px`，常规字重 `400`。 |
| 行高与字距 | 行高 `20px`，字距 `0`；编号内部保持完整、不换行。 |
| 颜色 | 当前浅色主题统一使用蓝灰色 `#42658a`，不随问题／笔记类型或批注高亮颜色变化。 |
| 标签间距 | 类型标签文字与编号文字之间为 `8px`，不因编号是否包在复制按钮中而额外增加内边距。 |
| 适用位置 | 原文边注、洞见边栏、洞见居中面板及问题详情使用同一编号样式。 |

验收时并排核对 Q、N 编号的字体、字号、字重、颜色及标签间距，并检查列表和详情中的显示一致性。窄窗口中编号仍须完整可见。

2026-10-17 的独立交互原型演示有回答和待回答的详情、Q/N 数字编号、编号复制及关闭返回；示例回答使用静态数据，新编号只在当前页面状态内递增，尚未接入 MCP 查找、保存或跨页面持久化。

2026-10-18 补齐原型中公式选区无法添加洞见的问题。显示公式使用独立块 ID，洞见保留原始 TeX 与公式编号，列表和问题详情显示排版后的公式，并可返回对应原式。当前选择公式的一部分也关联整条公式，不声称已经支持子表达式的独立定位；正文继续保留精确文字选区。

## 边栏与居中面板

| 形态 | 使用目的 | 当前布局方向 |
| --- | --- | --- |
| 右侧边栏 | 边读边查看问题、批注和笔记，与正文对照。 | 紧凑的分类与条目列表，点击条目可查看内容或定位原文。 |
| 居中面板 | 集中整理、回顾问题，阅读较长笔记和解释。 | 沿用阅读设置的临时面板形式，左侧条目列表、右侧所选内容详情。 |

两种形态共用同一份内容，切换时保留选中条目和正在编辑的内容，不重复打开两份洞见。两个不同快捷键分别指定边栏和面板；顶栏按钮的点击结果由 [阅读设置](阅读设置与快捷键.md) 控制。

关闭洞见只改变显示，不删除已保存内容。正文位置和未完成编辑的保留方式应在交互原型中验证，避免切换形态或返回阅读时丢失工作。

## 洞见与正文边注

洞见是内容的组织入口，边注是这些内容在原文旁的一种可选显示方式。关闭边注仍可从洞见查看全部已保存内容。

边注支持一键整体隐藏。打开右侧工具区时暂时收起边注，关闭后恢复原有显示偏好；进入洞见居中面板时也避免同时展示重复的洞见视图。哪些条目适合显示为边注，以及同一位置有多条内容时如何折叠，继续在原型中细化。

## 编辑、删除与撤销

2026-10-21：已接入现有阅读器。正文边注、洞见边栏、居中面板的条目与详情、问题详情使用同一个常驻 `···` 操作入口。菜单包含编辑、复制编号和删除；删除使用克制的红色并说明可撤销。菜单独立于正文定位与问题详情的点击区域，不把交互按钮嵌套在另一个按钮中。

| 场景 | 行为 |
| --- | --- |
| 编辑已有洞见 | 打开既有紧凑输入框，顶部显示正在编辑的类型和编号；保留原内容、颜色、类型及原文引用。显式保存才更新，取消保留原记录。 |
| 编辑问题 | 原回答及解决状态保留，并在编辑框中说明；从问题详情开始编辑，保存或取消后返回详情。 |
| 管理纯高亮 | 点正文高亮可进入对应洞见；菜单显示“补充批注”，也能删除。添加或清空批注不更换内部 ID、N 编号及原文引用。空问题和空笔记仍不可保存。 |
| 已有未完成草稿 | 再次编辑其他洞见时回到当前草稿并提示先保存或取消，不覆盖它。正在编辑的同一洞见暂时不能删除。 |
| 删除 | 使用服务端归档操作；成功后同步移除列表、边注及对应高亮。已回答问题明确显示“删除问题与回答”。其他洞见、正文及编号序列不受影响。 |
| 撤销删除 | 页面底部或洞见面板内显示原编号与撤销入口；连续删除按最近一次优先逐条恢复，恢复原编号、来源、内容和回答。 |
| 刷新与收起提示 | 撤销回执保存在当前标签页会话中，刷新或切换同一标签页内的文章后仍可使用；收起浮动提示不清空回执，洞见面板仍提供撤销入口。它不等同于跨设备回收站。 |
| 保存、删除或恢复失败 | 不伪造成功状态；保留草稿、现有条目或撤销回执并展示错误。网络结果未知时说明尚未确认结果，继续使用现有幂等请求与版本校验重试。 |
| 只读与键盘 | 只读文档禁用编辑、删除；菜单支持方向键、Home/End、Esc及焦点返回。窄屏菜单保持在视口内，列表滚动时跟随入口，减少动态效果设置下直接切换。 |

普通编辑不分配新编号。类型跨 Q/N 系列切换继续保留两个系列的别名；删除后的编号不回收。浏览器与 MCP 继续共用工作台的保存、归档和恢复命令，撤销回执不成为第二份权威内容库。独立样例也保留已使用编号，避免删除当前最大编号后重复分配。

## 来源与保存

用户在阅读器中的编辑和 ChatGPT 经 MCP 保存的内容使用同一份工作台数据。带位置的洞见需要保留稳定的文章、内容位置和版本关系，便于跳回原文和处理文档重新解析后的迁移。

针对具体文字的洞见同时记录它引用的是原文还是某种译文，以及字段或列表项位置，见 [双语对照](双语对照.md)。切换阅读语言不复制洞见，也不把原语言的摘录当成另一种语言中的精确选区。

ChatGPT 对话保留在外部聊天环境中。工作台保存用户指定留下的洞见，不自动复制完整聊天，也不依赖某个聊天会话标识作为文章或洞见的身份。

协作流程见 [ChatGPT 与 MCP 协作](ChatGPT与MCP协作.md)，数据定位见 文档处理与阅读器协同设计，界面细化见 页面组织与阅读体验待办。
