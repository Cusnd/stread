# 统一样式

应用控件、按钮、表单、弹窗与跨页面交互统一从[前端设计系统](design-system/README.md)进入。本页继续负责作者内容与阅读器外观的控制边界；下方带日期的界面主题描述属于背景，不是现有每种按钮的完整样式表。

> 本页保留产品约定及带日期的设计背景。早期研究稿、截图和个人待办不随公共源码发布；历史验证描述不代表当前发布包的验收结果。当前范围以根目录 AGENTS.md、现行服务合同及本仓库代码为准。

当前规则：Agent 决定内容分组、模块组合和必要布局，阅读器拥有统一外观与交互。本规则用于新的作者输入 `reader-authoring-1` 和 `reader-html-2`。统一外观不等于固定模板；同一组能力应支持不同内容的不同安排。已有 `reader-html-1` 保留原有解析语义，不在加载时重写或使旧引用失效。

## 控制权

2026-10-22 白色主题：正文、面板和主要操作采用白色表面，导航与辅助区域采用浅中性灰，文字、链接、键盘焦点和活动指示线使用炭黑。主要按钮以细灰边框、轻阴影和字重区分；选中项用白色或浅灰表面、深色文字及边线表达。首页、Collection、阅读器和弹窗共用 `styles.css` 的语义颜色变量。`--accent` 表示可读的交互前景色，白色操作表面使用独立的 `--action-surface`，不能把链接或焦点也变成白色。文献原图、批注色板和有语义的错误/成功色保持独立。

| 部分 | 内容/Agent | 阅读器 |
| --- | --- | --- |
| 内容 | 忠实保留文字、数值、公式、强调、语义标签、图像及关系 | 呈现内容与可靠顺序，不推断或改写事实 |
| 布局 | 自主选择分组、组合类、表格跨度、相对列宽、换行与对齐 | 执行保存的布局，管理可用宽度、容器回退、局部溢出 |
| 外观 | 通过语义与公共类选择角色 | 字体、字号、颜色、线条、留白、主题 |
| 交互 | 不写交互实现 | 展开、调整大小、批注、引用、双语和动效 |

## reader-html-2 的当前边界

新 HTML 默认无局部 CSS，使用共享样式。普通 table 和 HTML table 使用同一基础表格样式；普通图注和 HTML 图注也共享规则。字号由阅读设置控制，展开不会缩字号。视觉角色可以有统一定义的相对层级，但不能按某篇文章或表号特判。

2026-10-21 用户明确选择：每个图表可单独调字号，默认跟随正文。这替代此前强制一致的规则。正文、普通/HTML 表格、代码、算法文字和图表题注默认使用同一正文字号；用户在某对象的「大小」中指定字号后，只有该对象的内容及题注使用这个值，其他对象继续跟随正文。恢复默认或开启「跟随正文」时取消局部覆盖。图片内部的文字随图片整体缩放，不能由文字字号控件单独重排。英文/中文字体和代码等宽字体仍可不同，标题层级、工具栏及数学上下标保持各自语义；内容或 Agent 不得通过局部 CSS 指定外观。

同一语言、同一内容角色共享字体与留白，代码保留等宽字体、缩进和原始换行。自然语言表格先在可用宽度内换行；数学原子或多列结构的最小可读宽度超过容器时才局部滚动，不把所有表强制撑成不换行的最大宽度。题注中的段落分隔应可见。展开、手动调整对象宽度和窄屏回退都不改变内容字号。

公共类：`layout-stack / layout-pair / layout-grid`、`text-start / text-end / scalar / group-start / ruled / note`。它们的实际外观与响应式变化归系统管理。内容不覆盖这些类；局部自定义类只承担允许的布局。

布局示例见 [范例索引](../services/workspace/authoring-examples/index.md)。使用已有公共类时核对拼写；自定义类要由该块允许的 CSS 定义。未知或未被使用的 class/CSS 诊断说明布局意图可能未生效，不应把 JSON 校验通过当成类名已获得样式。

新 profile 的局部 CSS 仅允许 `display`、`table-layout`、`text-align`、`vertical-align`、`white-space`、`overflow-wrap`、`grid-template-columns`、`align-items`、`justify-content`、`flex-wrap`，以及使用系统 spacing token 的 `gap / row-gap / column-gap`。空间 token 首版为 `--reader-space-1 / --reader-space-2 / --reader-space-3`。保留 CSS 解析器、作用域、数值边界与可读顺序检查；禁止任意属性、全局选择器、隐藏/重排、资源 URL 和优先级覆盖。

颜色、背景、字体、字号、字重、边框、margin/padding 不允许写入新 profile 的局部 CSS。语义强调通过 strong/em，分组线用公共类；有实际语义的颜色或特殊符号须保存在来源及显式内容中，遇到不能表达的情形返回具体需求，不静默丢弃。profile 1 的旧样式可继续呈现；迁移到 profile 2 需显式编译和检查，不能只改版本号。

公共样式和内容布局分开存放。CSS/class 不进入翻译指纹；它们不能承载唯一的文字、关系或语义。内容结构、跨度、表头、链接、资源及数学仍进入指纹。

## 验证边界

验收应同时放置普通与 HTML 表格，比较同一角色的计算样式；用不同文档检查无需应用内的文档专属 CSS；在正常/较大字号、桌面较窄阅读容器、双语、原位展开及引用回跳下检查行为。局部相对列宽等已支持的作者布局是合法选择，不能与应用里的文章特判混为一谈。页面可见不代表全文内容已核对；程序通过不代表 Agent 自动转换成功。当前范例和改动需按各自证据报告。
