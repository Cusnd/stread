# Flow

2026-10-22：与 Collection 并列的一级页面。Collection 继续作为默认入口；Reader 的返回资料库行为保持不变。Flow 组织阅读中产生的洞见、接下来的阅读计划与实际阅读历程。

## 四个视图

- 总览：页头切换最近七天／最近三十天，紧凑统计与每日图表横跨内容区并保持固定；下方阅读记录、右上阅读计划、右下待回顾各自独立滚动，右栏容器本身不滚动。各组标题与“查看全部”固定在自身滚动体外，预览按自然内容高度展示。
- 洞见：跨文章检索笔记、批注／高亮和问题，按文章、类型、问题状态与待回顾筛选。选中后显示正文、原文与回答，支持回到原文、复制编号、进入现有编辑器、可撤销删除。
- 阅读计划：直接复用工作台的 planIds 和顺序，不再维护另一份计划。可以从 Collection 添加、上下调整、移出和开始／继续阅读。
- 阅读历史：按本地日期排列会话，提供今天、近七天、近三十天和全部范围。显示有效时间、可验证的章节／页码和关联洞见；打开对应文档版本与最后阅读位置、语言模式。

## 数据含义

总览在页头提供近 7 天／近 30 天切换，默认七天并记住选择。统计总量、柱状图和总览历史使用同一个本地日期范围；切换范围清除已选单日，并更新限量预览。三十天仍按每日展示，横轴间隔显示日期。有效阅读时间、阅读文章和阅读次数与图表组成横跨内容区的紧凑统计带，不使用独立指标卡片；阅读记录与计划、待回顾在其下方对齐。

图表可悬停／聚焦查看每日时长和阅读次数。点击某一天，在总览筛选当天阅读记录；再次点击或使用“全部日期”清除单日筛选，恢复当前范围的记录。左右键、Home、End 移动日期焦点，Enter／Space 切换筛选，Escape 关闭浮层。单日筛选不改变当前范围的图表与总量；总览的限量记录可在左侧独立滚动，更多记录通过“查看全部”进入阅读历史完整页。选择或清除日期、切换范围只重置左侧阅读记录位置，不重置右侧计划与待回顾的位置。无记录日仍可选择并显示空状态，跨午夜会话与洞见按当前时区归入对应日期。

鼠标离开悬停区域后立即关闭浮层，即使刚刚点击过该日期也不例外；不以鼠标点击后残留的焦点维持浮层。日期选中和历史筛选继续保留，键盘操作才显示对应的焦点提示。

“接下来”取自阅读计划的前几项。“待回顾”是用户主动加入的洞见集合，与问题是否有回答、是否已解决分开保存。完成回顾记录回顾时间并移出待回顾队列，不删除洞见，也不改变回答或解决状态。

阅读计时从此功能启用后开始；不从旧阅读位置、文章打开时间或文档长度推算历史时长。只累加阅读器可见、获得焦点且最近五分钟有活动时的区间。每十五秒提交一次；离开、失焦、隐藏、页面生命周期切换时截止当前区间。睡眠／计时跳变不补算；离线区间有持久待同步队列。服务端对重复投递和同一用户的多窗口重叠区间去重，并按时区拆分跨午夜区间。

阅读活动和回顾成员关系独立于正文修订。时间上报不推进工作台内容 revision；Flow 在上报完成、重新聚焦和前台周期检查时刷新，保留当前筛选与展开状态。

## 洞见标题与详情

2026-10-22：洞见增加独立、可选的 `title`。标题由用户填写，不从正文自动制造，不要求已有洞见补标题，也不以迁移为由改写原正文。标题的新增、修改或清空不改变洞见 ID、Q/N 编号、原文关联、回答和回顾成员关系。没有标题时直接呈现内容，不把整段正文当作大标题。

2026-10-23 补充授权：用户明确要求为当前 32 条开发洞见样例补写独立标题。这次内容编辑保留正文、身份、来源、回答和回顾状态，只对本次指定样例生效；不在渲染器、迁移或后续数据处理中自动生成标题。此前“已有无标题内容不自动补标题”的默认规则继续适用于未获授权的未来数据与其他既有数据。

洞见列表以独立标题作为主要阅读入口，限制内容阅读宽度，正文只展示最多两行预览。条目高度随实际内容自然变化，条目之间保留更大的间距，避免把长内容压入固定紧凑行。日期并入来源等次要元数据，不再单独放在行右端；来源与日期保持同一组，避免底部元数据零散排列。列表不重复显示 Q/N 编号，编号身份、按编号搜索、详情展示和复制能力保持不变。没有标题的洞见继续以普通正文预览呈现，不制造替代标题。布局调整保留原有选中状态、列表滚动位置、全部操作与完整详情入口，预览截断不裁减详情内容。

2026-10-23 问题状态细化：仅在 Flow 洞见列表中，用位于问题左侧的小图标替换行内“已解决／待解决”文字。阅读时间线原本没有这些状态文字，本次不为时间线新增状态图标。悬停提示与读屏名称继续提供明确状态，问题状态筛选、来源导航和打开详情行为保持不变。洞见列表的状态图标具有功能含义，极简模式仍保留；正常模式不在它旁边重复展示装饰性问题类型图标。

右侧栏用于快速查看，以普通正文字号展示简短预览，顶部提供打开完整详情的入口。完整详情使用更宽的面板，完整展示标题（若有）、正文、来源摘录和问题回答，继续提供回到原文、复制编号、进入现有编辑器、回顾与可撤销删除。侧栏和完整面板使用同一条洞见及同一套动作，回顾仍区分加入、完成与移出，不改变问题回答状态。

关闭完整面板后回到右侧栏的打开入口，保留选中的洞见、主列表位置和侧栏位置；关闭侧栏才取消当前详情选择。归档成功后回到仍存在的相邻列表项或 Flow 标题，撤销入口继续可用。面板内的长内容独立滚动，后台刷新和回顾操作不重置阅读位置。编辑、来源导航或其他操作失败时，在当前面板内保留可见错误与可继续操作的内容。Escape 先关闭当前操作菜单，再关闭详情面板；关闭动画与减少动态效果沿用共享约定。

## 布局

2026-10-22 用户再次纠正：**Collection 是 Flow 唯一的视觉基准，Flow 向 Collection 适配。** 商业化、克制、功能齐全和去除不必要装饰仍是目标，但不能为 Flow 另建一套视觉系统，也不修改 Collection 来配合 Flow。此前 Flow 的大页头、内缩轻灰右侧卡片和独立字号／间距方向被本次指令取代；Collection 自身的浅灰导航表面继续保留。四个子页复用 Collection 的导航、页头、筛选栏、列表和详情栏样式，按日期组织阅读记录的功能结构不变。

桌面布局以 Collection 的现有结构为准：全局顶栏高 56px，下方左导航默认宽 184px；目录页头与洞见详情页头均高 65px，主标题为 15px／600，详情标签、计数及辅助信息为 11px。页头左右内边距 26px、元素间距 9px；除下述洞见筛选区外，搜索框使用共享的 205px × 30px 规格，输入文字为 11px，筛选栏沿用 42px 高和 27px 高的 11px 按钮。范围切换、搜索和添加动作使用同一控件层级，不另造大标题、指标卡片或装饰性工具条。筛选栏沿用左右 26px 对齐线，仅在确有筛选内容的视图显示。总览计划与待回顾直接使用各自标题，不另加“阅读安排”页头。

2026-10-23 洞见筛选区细化：搜索从页头移入筛选区，与筛选控件统一为 32px 高并对齐。内容容器宽度不超过 620px 时，搜索独占一行，筛选选项在下一行保持成组排列；依据实际面板可用宽度调整，而非整个窗口宽度。保留清楚的控件组和行间距，避免搜索与筛选错位；不为日期或状态保留孤立的列表右列。

导航沿用 Collection 的 20px／12px 内边距、34px 最小行高和共享选中状态。内容列表沿用外侧 14px、行内 12px 的横向内边距，使行中文字与 26px 页头对齐；列表标题为 13px／500，次要文字为 11px，以 Collection 普通资料行的 58px 高度为紧凑基准。独立洞见列表与阅读会话按内容增长，不强压成单行；时间线内附属洞见的正文采用下述单行预览。阅读计划参考 Collection 的文章列、阅读状态列和行内操作对齐，保留顺序、保存位置、洞见数量、开始／继续、上移、下移、移出和添加，不使用另一套大字号表格。移除装饰性时间线圆点与连线、编号底块、重复摘要和空状态口号；文章、日期、有效时长和洞见仍完整关联。

2026-10-23 阅读时间线层级细化：总览与阅读历史复用同一结构，文章及其阅读时长、保存位置构成主层，关联洞见置于其下作为附属层。附属洞见仅在左侧缩进，正文最多一行预览；父级文章与子级洞见保持相同右边界，导航箭头沿共同右轴对齐。文章与各条洞见保留独立按钮及现有来源导航、阅读位置恢复行为，不嵌套按钮，不新增解释层级的标签。用缩进、字重与留白呈现父子关系，预览截断不改变洞见正文或详情。

2026-10-22 补充：阅读计划的“添加文章”与炭黑“继续阅读”保持相同的填充、白色文字／图标及更深悬停色，尺寸仍服从各自所在页头或行内控件的紧凑规格。鼠标悬停和行内控件获得键盘焦点时，整条计划行统一高亮，不能只亮标题局部。阅读、上移、下移和移出仍是独立控件，不通过嵌套按钮实现整行反馈，也不将悬停误当成已保存的选择。

Collection 与 Flow 共用一个持久化的左侧导航开合状态。在任一页面收起后，切到另一页面、经过加载占位或刷新时都保持收起，同源窗口同步更新。共享值优先于旧页面值；首次迁移时先取当前页面已有的开合值，再考虑另一页面，保留各自筛选、选中和滚动信息。首屏壳、顶栏开关与真实页面使用同一值，不出现短暂展开。此状态仅控制工作台左侧导航，不改变 Reader 的文章目录固定、悬停预览或 `tocMode`。

洞见详情沿用 Collection 的白色右栏结构：默认宽 306px，从全局顶栏下直接开始，内部独立 65px 详情页头，内容左右内边距 24px。总览右栏位于全宽统计带下方，与阅读记录起点对齐；“接下来”和“待回顾”按内容组织，不再保留重复的“阅读安排”标签或固定等高分区。两者继续使用白色表面，不增加卡片底、外侧留缝或包围圆角。洞见列表与详情仍独立滚动并保留各自位置；导航可收起，各完整页记住自身筛选、选择与滚动。保留共享图标、内容细线和控件边界，不添加整幅区域分隔线；只验证桌面交互。

2026-10-23 总览滚动最终修订：保留当前布局、炭黑配色、全宽统计带和左右对齐，导航、页头及统计区固定。下方分为三个独立滚动体：左侧阅读记录、右上阅读计划、右下待回顾；右栏容器自身使用 `overflow: hidden`，不承载整栏滚动。每组标题和“查看全部”位于各自滚动体之外并保持固定。预览内容自然排列，溢出后在所属区域滚动，不再使用 `FittedPreview` 或按高度减少条目。三分区方案取代此前双区、统一整页及禁止滚动方案；完整阅读历史、计划和洞见页继续保留完整数据与操作。

当前预览数量为阅读记录最多十条、计划最多三篇、待回顾最多五条；数量不随可用高度减少。计划按自然高度排布，以当前 35% CSS 最大高度约束其区域，剩余高度供待回顾使用；这不代表重新按高度裁减完整条目前缀。总览移除单独的“继续阅读”按钮，文章标题仍可进入阅读；历史记录的来源导航与阅读位置恢复保持完整。总览继续省略重复的“阅读安排”和“已保存阅读位置”提示，完整阅读计划保留位置信息和操作。仅总览使用当前 480px／内容区 44% 的右栏宽度上限，以保留阅读记录的主导空间。这些数量与尺寸是可调实现参数，不是用户要求永久固定的规格。

总览通过 `overviewScrollTop`、`overviewPlanScrollTop` 和 `overviewReviewScrollTop` 分别保存和恢复阅读记录、计划及待回顾的位置。选择／清除日期及切换范围只让阅读记录回到顶部，计划与待回顾各自位置继续保留。洞见列表与详情的独立滚动和位置保存继续保留。

三个区域分别在自身右缘使用原生滚动条并预留稳定空间，保留滚轮、键盘和拖动滑块行为。当前样式为 8px 宽、透明轨道、4px 圆角滑块，无上下箭头按钮；中性灰滑块透明度在静止、悬停／焦点、按住拖动时分别为 22%、44%、60%。不支持定制的环境使用细滚动条回退。这些视觉参数可调整，但不能改变三个独立滚动体或让标题随内容滚走。

Flow 调宽柄与滚动条的鼠标命中区域保持分离，继续支持鼠标拖动和键盘调整。当前采用独立 16px 中间列并留出 6px 间距，避免拖宽与滚动互相拦截；这些尺寸及具体中性色值均为实现选择，可在保持现有布局和交互边界的前提下调整。

切换阅读历史范围立即回到列表顶部；关闭洞见详情将键盘焦点还给原列表项，归档则回到相邻项或标题。添加文章窗口首先聚焦搜索框。侧栏调宽器向辅助技术报告实际宽度上限，键盘聚焦时仅突出短握柄。请求失败保留有效的重新加载操作，不展示无效关闭动作。

设置提供“极简模式／正常模式”，默认极简并保存选择。极简模式隐藏导航、快捷入口、洞见类型和历史文章的装饰图标，同时收回图标占用的空白；正常模式恢复它们及对应对齐，但不在功能性问题状态图标旁重复显示装饰性问题图标。Collection 的侧栏与资料列表共用这项偏好，Collection／Flow 顶栏设置和 Reader 阅读设置都可切换；同源窗口同步更新。问题状态以及新增、编辑、复制、关闭等功能图标在极简模式仍保留。

## 页面加载与导航反馈

2026-10-22：页面加载和切换保留共享导航壳与既有布局，避免依次替换整页加载提示而产生闪动。Collection、Flow、Reader 及较重弹窗按需加载；初次加载保留导航与内容区占位，返回已加载的 Flow 视图时先显示对应缓存，再更新数据。

导航栏下方使用临时 2px 炭黑动画线，不设置背景轨道，不预留额外高度，不推动内容。前台工作持续超过 120ms 才显示；一旦出现至少显示 180ms，工作完成后以 180ms 淡出并移除。它不表示虚构的完成百分比。后台轮询和缓存校验保持静默，不反复触发加载线。开启减少动态效果时，使用静态细线表达加载状态。

Flow 缓存按页面请求、日期范围和筛选条件对应；加载更多时保留现有条目。尚无响应时保留必要占位，不先展示零统计或空结果，再突然填入真实内容。取消导航不得让旧响应覆盖新页面；并行请求共用加载状态，接替请求先取得前台加载状态再释放旧请求，完成、取消或错误后正确结束反馈。

按需加载与数据更新保留 Reader 的未完成洞见、hash 定位、跨文章返回历史和阅读位置；Reader 模块及文档准备好后再一起显示，避免在正文挂载前开始定位或计时。弹窗首次加载后保留其状态，关闭动画和未提交输入继续有效。此线是功能性、临时的加载反馈，完成后消失，不恢复顶栏下方或页面区域之间的永久分割线。
