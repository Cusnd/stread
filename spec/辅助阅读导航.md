# 辅助阅读导航

2026-10-26：原稿没有章节小标题时，Agent 可以给已有内容添加简短的辅助导航标签。标签属于阅读导航，不是原文标题，不插入正文，也不改变来源、段落身份或洞见。相关责任见 [Agent 转换约定](Agent转换约定.md)，页面行为见 [阅读器页面设计](阅读器页面设计.md)。

## 内容与保存

作者输入可选 `navigation: { kind: "auxiliary", items: [...] }`。每项包含已有顶层块的 `targetKey`、纯文本 `text` 和整数 `level`（1–3），可用 `translations[language].text` 保存标签译文。条目数为 1–200，标签为 1–120 个字符，目标不得重复，按正文块顺序排列。没有辅助导航时省略该字段。

```json
{
  "navigation": {
    "kind": "auxiliary",
    "items": [
      { "targetKey": "layered-forward-pass", "text": "Forward computation", "level": 1,
        "translations": { "zh-CN": { "text": "前向计算" } } },
      { "targetKey": "backward-output", "text": "Back-propagation", "level": 1,
        "translations": { "zh-CN": { "text": "反向传播" } } }
    ]
  }
}
```

编译器把 `targetKey` 解析为已有稳定 `targetId`；导航不分配正文块身份，不进入正文文字索引，也不制造 `heading`。完整编辑包将 ID 还原为作者 key，经过语义往返检查后可用相同文档 ID 发布新 revision。精确删除块时移除指向已删除目标的条目，移动块时按新正文顺序调整导航；旧 revision 保留原记录，不猜测替代目标。

新作者输入严格验证；旧文档仍按既有无损读取规则保留未知数据。Reader 只使用能够解析到当前块的合法导航，不把无效数据当作正文错误。

## Reader 的固定规则

1. 有原文一级至三级标题时，沿用「目录」及原文标题层级。
2. 没有上述标题但有有效辅助条目时，显示「阅读导航」，采用相同的缩进、当前项、收起/固定及键盘行为。原文模式显示原标签，其他模式优先用当前目标语言的标签译文。
3. 两者都不存在时，不渲染空栏、标题或无效切换按钮，也不为固定目录预留宽度。只改变当前可用布局，不修改用户保存的目录偏好；切换到有导航的文章后按原偏好显示。

导航链接定位已有块；选区、阅读锚点、来源跳转和返回路径继续使用原身份。辅助导航可改善长篇无标题论文的可达性，但不代表对全文保真度的验证。`heading=0` 本身不是转换错误。

## 验收

覆盖有原文标题、有辅助导航、两者为空、失效旧导航、固定/收起切换、语言切换和桌面大小变化。核对点击与当前项追踪，确认切换文章后偏好仍保留。真实样本使用 *Learning representations by back-propagating errors*：原有 52 个块和零个章节标题保持不变，仅增加锚定既有段落的辅助条目。
