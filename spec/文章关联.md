# 文章关联

用户于 2026-10-22 同意实施第一版：资料库内参考文献匹配、引用预览、跨文章阅读与返回、反向引用，以及沿用“请求更改”的关联建立和纠正。

## 阅读行为

正文引用和参考文献条目共用一个文献预览。悬停或键盘聚焦可查看，点击可固定；正文选择、批注和请求来源选择保持优先。预览显示来源条目、已匹配资料或待核对候选。外部来源只在有可靠 DOI/arXiv 等标识时提供。

跨文章打开保存出发文章、来源位置、阅读模式和翻译语言。阅读器既有返回位置入口先处理篇内跳转，再返回来源文章；浏览器后退和刷新也保留本次阅读路径。反向引用从同一条关系计算，定位到引用出现的位置；没有可靠正文引用位置时，定位到文献条目，不能编造目标段落。

## 数据边界

参考文献仍是[文档格式](文档格式.md)中的普通块、列表项或受支持的 HTML 内容。文献身份、库内文件对应关系、引用位置、识别依据和用户确认独立于正文存储。尚未导入全文的文献也能存在；以后导入对应文章时可以补齐可读目标。

正文和译文指向同一文献身份。文件版本保留，不因题名相似合并预印本和正式发表版。自动匹配以标识和可核对元数据为据；年份、作者、标识等冲突保留为候选。语义相似不等于引用或支持关系，第一版不自动生成这类关系。

用户解除关联后保留决定；后续扫描和服务重启不应恢复已经否定的关系。恢复自动匹配是明确操作。文章修订导致来源变化时需重新核对，不能把旧关系悄悄挂到别的内容上。历史正文不显示当前版本关系作为历史事实。

## 请求与执行

沿用现有 R 快捷键和更改请求，不新增创建请求按钮。Agent 可读取文章关系、提出具体关联修改或执行已授权的修改。关系保存和对应请求完成必须在同一事务中，记录关系结果；不为纯关系变动创建正文版本。失败、版本冲突、仅提出提案时不完成请求。

保存请求不表示后台已经运行 Agent。标识匹配是服务确定性处理；需要内容判断的补全继续由读取请求的 Agent 执行。现有文档转换保持 [Agent 转换约定](Agent转换约定.md) 的职责边界。

## 第一版验收

- 引用已在库内的文献，预览和打开目标可用，原文/译文均可触发。
- 先导入引用文章，再导入目标文章，明确标识相同的旧引用自动补齐。
- 题名相同但年份不同保留为候选，允许明确确认。
- 从目标文章查看反向引用，定位来源文章的引用位置。
- 多次跨文章跳转、返回和刷新保留出发位置与阅读模式。
- 手工关联、解除、恢复匹配跨服务重启保存；请求完成幂等且有版本冲突检查。
- 本地实际浏览器验收使用隔离数据，不在用户资料中创建测试请求或改写正文。
