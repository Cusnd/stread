# 连续动效系统

> 本页保留产品约定及带日期的设计背景。早期研究稿、截图和个人待办不随公共源码发布；历史验证描述不代表当前发布包的验收结果。当前范围以根目录 AGENTS.md、现行服务合同及本仓库代码为准。

初稿 2026-10-23，分类规范同步于 2026-10-30。适用：Stread 桌面端的 Collection、Flow、Queue、Reader 与共享设置。跨页面选型、当前源码与差异见[设计系统：动效](design-system/motion.md)；以后相关修改同时更新这两处。

## 设计目标

用户要求：只要出现状态变化，就应有动画，符合“连续”的物理法则。

界面的目标状态可以立即改变，但屏幕上的物体必须有到达它的过程。视觉反馈表达变化的来源、方向和结果，不延后保存、导航意图或键盘输入。静止时界面安静；连续操作时，运动接着当前状态走。

这里的“状态”指用户能够感知的界面状态。计时器的后台 tick、无可见差异的数据校验、光标和用户滚动不另外播放装饰动画。输入、原生选区、滚动条与拖动本身已经是连续的直接操作，不能再加一层滞后的补间。

## 运动规则

1. **同一物体保留身份。** 列表项沿用业务 ID；正文、输入框、编辑草稿、独立滚动容器保持实例。页面交接由浏览器 View Transitions API 的被动视觉快照承担；快照不能交互，不复制 React Reader、输入框、观察器或阅读活动记录器，任何时刻只有一个活跃 Reader。不支持该 API 时直接提交同一导航结果。
2. **位置与速度接续。** 改变目标时从当前位置、当前速度重新求解。快速反向操作先减速再转向；不能把动画拉回预设起点，也不能排队等待上一段播放完。
3. **质量有层次。** 控件最轻，内容次之，浮层和侧栏更重。整体使用临界或接近临界阻尼，收敛清晰，不持续回弹。
4. **空间关系稳定。** 侧栏从所属边缘进退，居中弹窗在原中心附近升起/沉下；页签内容的轻微横移遵循页签顺序；列表让出或填补空间。
5. **边界可被打断。** 用户的滚轮、拖动、历史返回和新操作优先。动画结束回调必须核对当前代次，不能关闭已重开的面板或清除新的草稿。
6. **退场完整、语义及时。** 关闭意图一到，退出控件即 inert；视觉结束后才卸载、关闭原生 dialog 或释放其滚动锁。辅助技术只感知当前有效状态。
7. **减少动态效果实时生效。** 系统偏好改变时，活动动画立即到达目标；位置、结果和可访问性保持完整。

## 节奏与实现参数

空间过渡使用 Motion 的物理弹簧，参数统一定义在 `prototypes/insight-composer/src/motion-system.js`。

| 用途 | stiffness | damping | mass | 视觉要求 |
| --- | ---: | ---: | ---: | --- |
| 控件、选中指示 | 600 | 45 | 0.7 | 迅速响应，轻但不跳 |
| 内容、提示 | 500 | 45 | 0.8 | 短距离交接 |
| 任务详情展开（disclosure） | 180 | 28 | 1 | 高度推动后续内容，保留可感知的展开过程 |
| 对话框、浮层 | 420 | 42 | 1 | 从触发语境进入，完整退场 |
| 工具侧栏 | 360 | 38 | 1 | 有重量、无明显回弹 |
| 列表与布局 | 300 | 35 | 1 | 相邻内容自然让位，不缩放文字 |

共享 Motion 组件的普通透明度使用 140ms 线性变化，任务详情 disclosure 使用 200ms；颜色、边框和阴影使用约 120–160ms 的短过渡。页面视觉快照单独采用 120ms 淡出与 220ms 淡入，进入画面最多轻移 6px；这是页面内容的交接，不是可交互物体的弹簧模型。弹簧的实际时长由距离、速度和静止阈值决定，不能把这些参数误报为固定播放时间。弹窗面板、灰幕与背景模糊按相同可见节奏退出，不能让模糊等待弹簧尾段才清除；当前各容器差异见[弹窗与浮层](design-system/overlays.md)。

主动文章定位采用解析临界阻尼：每帧更新目标位置，保留当前位置和速度，在正文重排中继续收敛；最长 900ms。初次恢复、被动布局校准、拖动与用户滚动仍直接更新，不制造二次漂移。

## 状态覆盖

| 区域 | 状态变化 | 运动表达 | 必须保留 |
| --- | --- | --- | --- |
| 全局页面 | Collection / Flow / Queue / Reader 进入、返回 | 内容快照淡接；共享顶栏保持在场；首次懒加载保留旧内容和原加载规则 | 单一活跃 Reader、历史、延迟加载、最新导航意图 |
| 主导航 / 分类 | 展开、收起、切换选中项 | 导航占位宽度弹簧变化，选中背景/下划线沿布局移动 | 共享偏好、文本不缩放、导航焦点 |
| Collection | 搜索、筛选、排序、分类、归档和恢复 | 同键行原位移动，新增轻入，退出淡出、相邻项补位 | 行身份、详情选择、单击/双击语义 |
| 资料详情 | 选中资料、展开摘要、状态和计划动作 | 内容交接，真实高度变化，功能状态即时成立 | 编辑内容、阅读位置、快捷阅读动作 |
| Flow 页面 | 分区切换、列表和详情切换 | 内容交接；列表/侧栏各自运动，不移动滚动坐标系 | 四个分区状态、各自滚动与焦点 |
| Queue | 类型筛选、任务展开/收起、预览加载 | 退出行及时释放占位，详情用 disclosure 高度过渡，预览预留空间 | 行内动作、原生选择、相邻行稳定、Reader 返回位置 |
| Flow 统计 | 7/30 天、日期选择、tooltip | 柱高接续、选中态过渡、悬停提示进退 | 真实值、单日过滤、键盘/鼠标提示区别 |
| 阅读计划 | 加入、移出、上下移动 | 行退场、补位和重排弹簧 | 计划顺序、焦点回到相应功能控件 |
| 洞见 | 类型/状态/回看过滤、归档/恢复、预览/全文 | 列表位置连续，详情进退完整，标识短过渡 | 原文来源、稳定编号、问题答案状态 |
| 设置 | 打开、关闭、页签、开关/选项 | 弹窗浮起/退回，指示器接续，内容轻微定向切换 | 固定面板宽高、每页常驻滚动、当前打开比例 |
| Reader 框架 | TOC、边注、原页、洞见、术语工具 | 从对应边缘展开/收回，正文空间协调变化 | 选区、草稿、阅读行、原页坐标 |
| 文章定位 | TOC、引用、洞见、原页反向定位、返回原位 | 可取消的连续减速定位，重排时持续校准 | 当前速度、最终源地址和返回点 |
| 编辑器 | 选择入口、展开、标题、类型/颜色菜单、保存/取消 | 保留 textarea，尺寸与菜单连续变化，关闭后再卸载 | 光标/IME、未提交正文、请求身份 |
| 引用 / 问题 | 预览出现/移动/替换、详情开合 | 预览完整进入/退出，内容更新接续 | 原文身份、编辑/回看功能、焦点返回 |
| PDF / 图片 | 翻页、图片完成、缩放、工具反馈 | 新内容准备完成后交接，直接缩放/拖动跟手 | 页码、源框、比例、原生灯箱能力 |
| 异步反馈 | 加载、成功、错误、空态、撤销、禁用 | 局部提示进入/退出，颜色与透明度反馈 | 真实操作结果、重试入口、无伪进度 |

## 不变量与禁止项

- 不使用全局 `transition: all`，也不使用 MutationObserver 对所有 DOM 变化猜测动画。
- 不通过整体缩放正文、复制活跃输入框或重复挂载文章实现转场。
- 不给长列表叠加逐项延迟；可见项同时响应，不让用户等完几十行。
- 不把数字统计从零虚假计数到真实值；图形可以插值，数值立即准确。
- 不用退出定时器替代实际完成；所有异步动画回调有代次保护。
- 设置的标题、页签、完成按钮和外框不随页内内容运动。
- Flow 的三处 Overview 滚动及 Insights 列表/详情滚动保持独立；拖动分隔条时无弹簧滞后。
- 原有 120ms 加载延迟、180ms 最短显示、180ms 退场及静态 reduced-motion 分支继续有效。

## 演示与验收

从仓库根目录运行 `npm run desktop:demo`，准备或核对数据后打开独立 Electron 开发窗口。固定 profile 为 `.audit/continuous-motion/demo-profile/`，资料库、浏览器偏好、草稿与后续阅读活动都保留在其中，不计入正式资料库。详细运行方式见 [桌面程序说明](../electron/README.md#连续动效演示)。

运行演示准备脚本后，独立 profile 中生成的 `demo-manifest.json` 记录初始基线：14 份资料（12 份可读、2 份归档）、96 条洞见、24 条术语、6 条模拟请求、8 条计划及 50 条模拟会话，覆盖 30 天、空日期和 2 条跨午夜会话。其中 4 份资料为仓库自带的真实 PDF 样例，10 份为标记清楚的模拟双语文章；洞见、答案、计划与阅读统计均为演示数据。新文章通过冻结作者预览发布，不以此宣称已完成视觉验收。

重跑已有完整清单的演示库时只读校验，不重新生成或覆盖手动修改，也不自动更新模拟日期。清单的初始数量与手动试用后的实时数量可以不同。核对命令为 `node scripts/seed-motion-demo.mjs --verify`，需要先关闭使用这个 profile 的窗口。脚本拒绝任意目标路径、运行中的演示库和未知数据库。

重点看连续的中间帧，而不仅是结束截图：快速开/关/再开；移动中换目标；列表连续移位；关闭时输入保护；拖拽瞬时跟手；系统减少动态效果；页面返回后的草稿、焦点和阅读位置。

验收证据与覆盖情况另见 `.audit/continuous-motion/report.md`。这份设计表是目标与约束，不能代替真实桌面验收结论。
