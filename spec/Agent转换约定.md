# Agent 转换约定

2026-10-27：入口说明保持简短，提供目标格式、原件、工具和验收条件；提取、组织、生成、任务拆分、检查与修复方法由调用 Agent 自主选择。当前约定取代此前要求每个新调用者填写 v2 固定检查表、逐块覆盖数组和多份专用证据 JSON 的做法。

> 将指定原文件转换为 `reader-authoring-1`，保留完整原文；非中文默认提供完整简体中文。实际启动未参与生成的独立 Agent，先读原件，再对照候选核验内容与译文，并打开真实 Reader 检查显示和交互。修复后复查最新候选，仅发布复审通过的同一版本。返回阅读链接、独立复审记录及未解决问题；未完成的检查须明确说明。

## 格式和入口

调用 `get_authoring_contract` 获取[简短作者指南](../services/workspace/authoring-guide.md)、[严格 schema](../services/workspace/authoring-schema.json)、[最小双语示例](../services/workspace/authoring-minimal-example.json)及[复审提交说明](../services/workspace/conversion-workflow.md)。复杂表格、HTML、前置信息与导航按需查阅[格式参考](../services/workspace/authoring-format-reference.md)和[布局示例](../services/workspace/authoring-examples/index.md)，不要求先读全部项目 spec。

Agent 提交元数据、原件引用与按阅读顺序排列的内容块，使用稳定 key；内部 ID、索引、来源指纹和译文状态由编译器生成。保留事实、数字、公式、图表、脚注、参考文献和语义关系。正文没有标题时可使用独立[辅助阅读导航](辅助阅读导航.md)，不能伪造原文标题。无法确认的来源区域不补猜。

Agent 选择标准块或语义 HTML，Reader 负责统一字体、颜色、留白及交互。PDF 分栏和分页不必机械照搬，原文内容和关系必须完整保留。语言无关公式、数字、原图共用；学术姓名和标识可以保留。完整译文的范围及字段对应见[双语对照](双语对照.md)。

## 复审和发布

默认使用一份 `reader-quality-review-3` 记录，绑定精确预览 ID/hash，记录真实生成者与独立审阅者会话、原始启动证据、一次审阅结论、支持材料及发现的问题。服务提供全篇或受影响范围；`verified` 表示该完整范围已被实际检查。审阅者自行选择充分的检查方法，在结论中说明检查条件和限制。

原件先读、真实独立会话和 Reader 检查仍是完成条件；它们不能靠角色改名、自评 PASS 或伪造证据代替。普通审阅笔记、截图或日志均可作为支持材料，不强制原件清单 JSON、单独运行记录、三个时间戳或逐字段相同译文例外。相同原译文字段继续作为语义检查提示；缺译仍阻止默认交付。

修复生成新的不可变候选，复审绑定新的 hash。失败、未解决阻塞项、缺译或缺少实际独立/Reader 复审不能被另一份 PASS 掩盖。旧 v2 保持原有更严格检查；历史 v1/文字记录保持可读但不能单独完成发布。[转换质量反馈](转换质量反馈.md)说明结果和证据边界。

已有文章先获取 `read_resources(kind=authoring_artifacts,mode=editing)` 的完整编辑包，复用身份及资源绑定，以当前版本为 target 发布新 revision。只读片段不能充当完整编辑输入。预览、修订、资源、引用、版本及幂等回执保护保持不变。

Reader 本地保存原件、作者输入、资源、文档和审阅记录；工作台服务不调用模型，也不启动或编排 Agent。外部 MCP 调用端负责实际启动独立审阅者、修复复查和准确版本发布；桌面内置接入已于 2026-10-28 移除。服务核对结构、字节、绑定和声明一致性，不能认证所有外部宿主身份或证明语义结论。验证报告区分协议测试、真实独立运行、原件对照和实际 Reader 检查；经过人工补救的结果不能称为独立冷启动成功。
