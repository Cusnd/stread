2026-10-18：用户明确指出，旧版“现代工作台”与当前阅读页气质不一致，界面杂乱，缺少成熟产品应有的小巧与精致。本轮按阅读页的浅中性色、紧凑控件和克制的信息层级重做交互设计稿。保留此前确认的分类、资料列表、常驻详情三栏关系。旧版深色导航和较大标题不再作为设计基准。

## 当前实现

本页保留 Collection 的设计约定。当前实现位于 [CollectionPage.jsx](../prototypes/insight-composer/src/workspace/CollectionPage.jsx)，连接本地工作台。早期独立 HTML 设计稿和导出脚本未随公共源码发布。

## 页面目的

2026-10-22：Collection 作为应用默认入口，名称保持 Collection，帮助用户收纳、查找和组织资料，查看阅读状态与阅读计划，并进入或继续具体材料的阅读。独立首页已移除，阅读器承担正文与洞见。页面分工见 [页面组织与阅读体验](页面组织与阅读体验.md)。

资料列表是本页主体。分类决定查找范围，详情帮助用户判断是否开始阅读。标题、状态和主要动作先被看见，分类路径、标签和上次问题按需提供上下文。

## 布局与视觉

| 区域 | 新稿方向 |
| --- | --- |
| 顶栏 | 56px 高，保留页面识别、分类开合和必要动作。控件风格沿用阅读页。 |
| 左侧分类 | 浅中性背景，桌面约 184px。分类层级用缩进表达，选中项使用浅蓝灰底色。 |
| 中间列表 | 一个小标题、搜索和紧凑筛选。每行以资料标题为主，类型和标签放入次级文字，阅读状态单独对齐。 |
| 右侧详情 | 桌面约 300px 至 310px。展示标题、简介、阅读位置、阅读与计划动作、分类、标签和已有问题。 |
| 窄窗口 | 分类和详情通过明确入口打开，保留选中资料与筛选。不能只隐藏详情而失去阅读入口。 |

不再使用大标题、介绍口号、重复面包屑、常驻整排标签和装饰封面。详情标题采用自然换行的衬线字，与阅读页正文形成联系。列表标题约 13px，次级文字至少 11px。精致感来自对齐、间距和信息取舍，不能靠过小或过淡的文字实现。

## 筛选与选择

分类、搜索、阅读状态和标签共同确定当前结果。父分类包含子分类中的资料，多标签同时满足。阅读计划独立于已读、在读、未读状态。未读资料可以不在计划里，已读资料也可以重新加入计划。

筛选后，当前选中资料仍在结果中就保持选中。否则选择第一条结果，无结果则清空详情。列表、详情和数量由同一份状态生成，不能让详情继续显示已经被筛掉的资料。关闭预览后恢复原来的列表位置、筛选和选中项。

标签与排序通过临时控件打开。活跃条件应可识别并可清除。输入搜索时保留输入框与光标，更新结果不能打断连续输入。

## 验证边界

分类、搜索、筛选、选择、阅读计划、详情与阅读器返回均须针对当前应用验证。历史设计稿中的示例状态不能代替真实服务和桌面检查。资料上传与转换遵守 [文档转换](文档转换.md)，页面返回与阅读状态遵守 [页面组织与阅读体验](页面组织与阅读体验.md)。
