## 入口与视图

顶栏“原页”打开右侧原页工具，按当前正文内容定位一次。原页与洞见边栏共用右侧工具区；关闭或切换工具时保留正文阅读位置，布局见 [阅读器页面设计](阅读器页面设计.md)。

原页每次呈现一张完整 PDF 页面，复用原始文件而不重新排版。默认同时按面板内实际可用宽度和高度计算整页适配比例，保持长宽比并在两个方向居中；页头、工具栏、页脚和内边距不计入页面可用空间。拖动面板分隔线或调整桌面窗口大小时重新计算整页比例，不能仅适配宽度而使页面底部被裁掉。

面板提供明确的上一页、下一页和当前页码，原页面板获得键盘焦点时支持 PageUp / PageDown 翻页。默认整页视图不依靠连续纵向滚动查找下一页。用户主动放大后可以在当前页内手动平移；正文在同一页内改变阅读块或选区时保留当前缩放与平移位置，不重新居中、不自动追逐高亮区域。切换来源页时显示目标页；回到整页适配时重新完整居中。

可以渲染为页面图像或等效页面视图；具体渲染实现与加载范围通过真实文件验证。另行打开浏览器原生 PDF 只用于查看或下载，不承诺能与那个外部窗口保持双向同步。

阅读设置提供“正文与原页联动”开关。首版建议初次使用开启，最终默认值与偏好作用范围在原型中确认；开关只控制自动跟随，明确的定位动作仍然有效。必要的快捷入口放在顶栏，不在正文增加常驻按钮。

## 双向行为

| 用户操作 | 预期行为 |
| --- | --- |
| 滚动正文，且联动开启 | 以当前实际阅读块为目标更新来源高亮；若目标仍在当前 PDF 页，页面位置完全不动；来源跨页时才切换页面。不能一直追随此前选中但已经离开视口的段落。 |
| 鼠标悬停或移动到正文的另一内容块，且联动开启 | 无需点击，按指针实际所在的稳定块更新对应原页和高亮；原文与译文使用同一来源关系。同页只换高亮，跨页才切换纸张，保持响应灵活且不抢焦点。 |
| 按住鼠标拖动选择正文文字 | 保留浏览器原生选择和既有跨块选区映射；鼠标按住期间不以悬停块覆盖正在形成的选区，不阻止拖选或改写选区范围。 |
| 点击或选择正文中的段落，包括译文 | 使用同一稳定块 ID 更新对应来源高亮。目标仍在当前 PDF 页时只改变高亮；在其他页时切换至目标页。点选是明确定位，联动关闭时仍有效。 |
| 手动点击上一页 / 下一页，或在原页面板按 PageUp / PageDown | 切换当前原页。仅在联动开启时，让正文跟随该页可确认的来源块；联动关闭时正文位置保持不变。没有可靠映射时不猜测正文位置。 |
| 放大后在当前原页内手动平移 | 仅改变用户查看该页的位置，不把平移像素换算成正文滚动，也不让随后同页正文选区把原页拉回。 |
| 点击 PDF 中有映射的内容区域 | 跳到对应正文块并临时突出该块；保留跳转前位置，支持返回。多栏之间的空隙或无映射空白不触发随意跳转。 |
| 从正文明确请求定位原页 | 使用当前块或明确引用的块更新页码与高亮；同页不平移原页，联动关闭时仍可执行。键位与顶栏呈现随原型细化。 |
| 关闭联动后分别阅读两边 | 正文滚动、鼠标悬停与原页手动翻页均不自动带动另一侧；明确的段落点选、区域点击与定位动作仍有效。重新开启时以最后实际操作的一侧为起点，按块或当前页对齐一次；无有效记录时以正文为起点。同页对齐仍只更新高亮。 |

“双向”指正文阅读块或指针所在块带动原页页码与高亮、手动原页翻页在联动开启时带动正文，以及始终可用的区域点选定位。它不要求两边按像素同步滚动。保证块与可靠来源区域级对应，不声称拥有逐字或双语逐句的精确映射。

## 谁控制位置

鼠标仍在正文内时，段落间距和被忽略的行内控件不让出指针定位优先级。经过空白处保留上一段高亮，进入下一段后再更新；不能暂时跳回视口顶部或旧选区。动画帧中重新读取指针当前位置对应的元素，避免滚动期间沿用上一帧的命中结果。鼠标离开正文或用户改用键盘滚动后，才恢复对应的阅读位置规则。

以用户最后实际操作的一侧为当前驱动方，区分正文滚动、指针悬停、文字拖选、段落点选、原页翻页、原页区域点击及放大后的页内平移。程序为同步而产生的正文滚动或原页切换不取得驱动权，也不反过来再次触发跟随；用户转到另一侧操作时及时交接，避免来回振荡和位置被拉回。页内平移仅保留用户的观察位置，不触发反向正文定位。悬停只作用于实际正文内容块，工具按钮、面板和正文外空白不构造来源目标；文字拖选期间让选区处理优先于悬停处理。

两侧用块 ID、来源页与可靠区域建立联系，不用整篇滚动百分比或页内像素位置互相换算。同一页内高亮变化不改变页面几何位置。字号、行宽、语言模式或工具宽度变化时重新测量布局，并保留同一阅读内容；整页适配重新计算可用宽高，不能把重排误判成用户主动跳转。

明确点选和引用跳转需要可返回的阅读位置；自动联动不为每个滚动事件创建一条返回记录。原页关闭或隐藏时不继续控制正文。当前阶段以桌面窗口、鼠标与键盘操作验证，不扩展手机界面或手机测试。

## 来源映射与不足时的行为

沿用 [文档格式](文档格式.md) 的 `block.source: [{page, box}]`，无需另建第二套正文身份或映射协议。

- `page` 是 PDF 文件中从 1 开始的实际页序，不是印刷页码或页脚标签。
- `box` 相对于按有效页面边界和旋转方向显示后的原页，左上为原点，归一化到 0–1。转换器与渲染器须使用相同坐标约定；裁剪、旋转和缩放必须实测，不凭字段存在就认为位置准确。
- 同页跨栏、跨页内容保留多个独立区域；高亮与点击命中逐个区域处理，不合成一个覆盖栏间空白的巨大矩形。区域顺序跟随来源中的内容顺序；正文反向定位可保留正在查看的有效区域，首次定位从首个可靠区域开始。
- 高亮使用中性灰色的半透明、轻圆角段落包围框，保留克制的细边与间距，让原文字形清晰；同一页同一段的连续文本区域合成连贯的视觉包围框，避免逐行灰条。视觉包围框与可靠坐标、点击命中保持分离；不同段落、页面或不连续栏区仍独立处理。该高亮是临时来源指示，不改变已保存洞见的颜色。
- 可在校验原文件版本后，从声明的来源页中可靠匹配原文并派生坐标；缓存须绑定文件哈希与原文内容，不能因此改写文档修订、稳定块 ID 或原始来源记录。不能用图表标题的文本位置冒充整个对象的区域。
- 普通表格与语义 HTML 表格使用同一稳定对象身份。缺少明确坐标时，可根据声明来源页内的表格结构和单元格内容确认整表边界；歧义或证据不足时保留页级定位。悬停、点击或选择任一单元格与题注都指向同一个整表高亮，译文和展开状态沿用相同来源；表内移动不拆成逐单元格高亮，尺寸控件不触发定位。派生缓存须包含参与匹配的内容及算法版本，不能沿用只含题注或段落字段的旧缓存。
- 缺少坐标但有可靠页码时安静降级为页级定位，显示可靠页码对应的原页，清除不属于目标的旧高亮，不画伪精确的文字框。无需显示“仅定位到页，暂无可靠的段落位置”等精度标签或常驻说明。手动原页翻页且联动开启时可落到该页首个可确认的来源块。
- 当前块完全没有可靠映射时保留现有 PDF 页并清除无关高亮；当前 PDF 页没有正文映射时保留正文位置。此类正常的映射不足不新增可见状态标签，不猜邻段或按篇幅百分比强行跳转。
- `origin: "user"` 的用户补充不构造原页高亮，也不使用前后段的页码冒充出处；无需为每次悬停额外显示“用户补充，无对应原页”。来源段落的纠错仍可使用核实后的旧映射；拆分、合并或重新转换后必须重新核对映射。
- 原文与译文共用块 ID 和来源位置。切换为译文或双语仍定位同一 PDF 区域；从 PDF 回到正文时保留当前语言模式，按块定位而不猜译文中的相同字符偏移。
- 原页资源必须对应文档记录的原始文件版本。无法读取原文件、页面加载失败、来源文件版本不一致等真实错误仍显示具体状态；移除普通精度标签不能隐藏这些错误。不得拿另一版本 PDF 继续做看似正常的同步。

非 PDF 来源不伪造 PDF 能力；按实际来源提供可用的查看方式，不影响结构化正文阅读。

## 参考证据与验收

早期参考实现的代码和模拟 DOM 测试未随本仓库发布。它们不能代替本项目的真实 PDF、来源坐标与界面验收。

本项目须用真实 PDF 验证：在多个桌面窗口和拖动面板宽度后保持完整居中页；同页正文滚动、原文与译文悬停、段落点选和译文选择仅更新灰色圆角高亮而不改变原页位置；跨页阅读或指针目标切换目标页；上一页 / 下一页及 PageUp / PageDown 在联动开关两种状态下正确带动或保留正文；PDF 区域点击在联动关闭时仍可明确定位并返回。放大后手动平移，再悬停或选择同页其他段落，须确认平移位置未被重置。

另须验证无需点击即可跟随指针、鼠标按住跨段拖选时不被悬停覆盖、联动关闭后悬停不跟随而明确点击仍可定位、页级对应不画假高亮也不显示精度标签，以及真实来源文件与页面加载错误仍可见。

同时验证输入交接、单栏与双栏、跨页块、旋转或裁剪页、页级和无映射降级、双语切换、用户补充，以及排版与工具开关后的位置保持。记录浏览器操作与可见结果，不以参考测试通过代替本项目完成。
