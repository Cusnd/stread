# 自定义 HTML 内容块

> 本页保留产品约定及带日期的设计背景。早期研究稿、截图和个人待办不随公共源码发布；历史验证描述不代表当前发布包的验收结果。当前范围以根目录 AGENTS.md、现行服务合同及本仓库代码为准。

本文是 schema 2 的 HTML **存储与渲染合同**。转换 Agent 使用 [作者指南](../services/workspace/authoring-guide.md)，在 HTML 中按需写 `data-key`；工具自动分配节点身份、派生索引和指纹，不要求 Agent 手填本页的运行时字段。

当前作者输入生成 `reader-html-2`，使用下文的语义 HTML、双语和引用规则，局部 CSS 仅限 [统一样式](统一样式.md) 定义的布局能力。既有 `reader-html-1` 继续按旧 CSS 合同读取；不能把旧 profile 的外观属性用于新作者输入。两者的区别见下文“局部 CSS 与旧 profile”。

早期混合排版研究和 Attention 表 3 小样是设计背景。当前作者服务和验证边界见 [文档转换](文档转换.md#验收)；已有样本不代表任意 HTML、全部论文版式或无人干预转换均已验收。

## 使用边界

标题、段落、普通列表、公式、图片和简单表格继续走标准块。复杂表格、算法或图文组合可以使用一个显式 `html` 块；同一对象不再人工维护一份同义 JSON 内容树。仅仅很宽不要求改成 HTML，仍优先使用可用宽度、局部滚动和展开。

HTML 保存 Agent 根据内容选定的结构与局部布局。阅读器打开文档时按通用合同执行该安排，不重新调用 Agent 排版。Agent 可以为不同内容选择不同组合；通用合同保证相同语义和布局能力被稳定实现。一个块覆盖一个有共同布局意义的对象，不把整篇文章塞进 HTML 来绕过标题、来源和局部修订。

研究中的跨度、真空白、统计层次、表注、算法步骤、原始双语及跨页关系必须保留。HTML 不负责推断续表或题注归属，也不能把没有可靠结构的截图宣称为完整结构化内容。

## 数据字段

| 字段 | 规则 |
| --- | --- |
| `id`、`type` | 稳定块 ID；`type` 固定为 `html`。 |
| `html_profile` | 存储字段必填。新作者输入由编译器生成 `reader-html-2`；既有 `reader-html-1` 保持旧语义，不支持的 profile 显式降级。 |
| `html` | 必填 HTML 片段。HTML 是该块的正文来源；检索和引用索引由程序生成。 |
| `css` | 可选、只用于块内部的局部 CSS。省略等于使用统一样式。内容与 CSS 分开检查。 |
| `language`、`origin`、`source`、`extensions` | 沿用 [文档格式](文档格式.md)。用户补充不继承附近 PDF 坐标。 |
| `role`、`num` | 可选来源角色及原编号；如 `role: "table"`、`num: "3"`。不以编号选择专用渲染分支。 |
| `translations[语言].html` | 可选完整目标语言片段；共用块 ID，内部同一内容沿用相同节点 ID。译文不另携带 CSS。 |
| `translations[语言].source_hash` | 按下文指纹规则记录翻译依据；缺失、匹配、过期是不同状态。 |
| `fallback` | 可选对象：`image` 是文档相对资源路径，`alt` 是说明。原文 `source` 仍是核对原页的依据。 |
| `reference_mappings` | 可选、迁移产生的旧地址到内部节点的映射；不是第二份当前正文，规则见下文。 |

首次发布 HTML 正文能力使用 `schema: 2`，不重新解释 schema 1，也不把 HTML 藏进旧端可忽略的扩展字段。旧文档可继续按 schema 1 读取；新增 HTML 文档由支持 schema 2/profile 的消费者读取和保存。

## 共享的语义 HTML 范围

两个 profile 采用相同的语义 HTML 标签范围：`figure/figcaption`、`div/section`、`p/span`、`strong/em/b/i`、`sup/sub`、`blockquote`、`pre/code`、`br`、`a/img`、`table/caption/thead/tbody/tfoot/tr/th/td`、`ul/ol/li`、`dl/dt/dd`。不接纳完整网页的 head/body、脚本、自定义元素、事件处理器、表单或 iframe。文章章节仍使用标准 `heading` 块；HTML 对象内不支持 h1–h6，也不另生成文章目录。

元素属性采用明确允许集合：局部 class、真实 lang、说明 title，以及对应标签的链接、资源、跨度、表头关联和列表编号。禁止原样注入 style、任意 data 属性或应用保留属性。HTML 和 CSS 使用真实解析器，不能用字符串替换或单个正则充当完整解析。

- `data-node-id` 是工具生成的存储身份，标识可引用的段落、格、题注等单元；正式文档内与其他引用身份不重复。源/译同一节点 ID 代表配对关系。节点不能相互嵌套；需要更细粒度时将身份放在较小单元上。允许在 figcaption、div、section、p、span、strong、em、b、i、sup、sub、blockquote、pre、code、a、caption、th、td、li、dt、dd 上设引用 ID；表格行组、行、列表容器、图片和数学原子不能自身承载引用 ID。作者输入仅按 [作者指南](../services/workspace/authoring-format-reference.md#semantic-html-identity-and-reader-owned-layout) 提供可选 `data-key`。
- 真实文字必须处于一个可引用节点内。普通结构容器可以没有节点 ID；结构间格式化空白不作为正文。
- 数学使用空的 `<span data-tex="…"></span>`，保留原 TeX，由受控数学组件呈现。引用按数学原子处理，不读 KaTeX 展示节点的重复文本。
- `rowspan/colspan` 必须是正整数；表格不能碰撞、缺格或越过行组。`headers` 引用块内真实表头节点，`scope` 保留来源关系。覆盖槽位不是一个空单元格。
- 空单元格确有“同某格”含义时，可用 `data-same-as="节点ID"` 保留关系；必须指向同表的真实格，并有来源题注或证据支持，不能据空白自行推断。
- 图片使用文档内相对资源，保留 alt 和可靠的固有尺寸；普通链接只接受显式 HTTPS/HTTP 或内部目标。运行时统一命名空间化节点及链接，文档不能伪装应用控件。

## 局部 CSS 与旧 profile

`reader-html-2` 优先使用共享 `layout-stack/pair/grid` 等类。局部 CSS 只允许 display、表格布局、对齐、文字换行、相对列关系和使用系统 token 的间距；精确属性与值范围见 [统一样式](统一样式.md)。它不允许作者指定字体、字号、颜色、边框、margin/padding 或覆盖公共类。Agent 通过语义和布局表达关系，阅读器管理外观。

`reader-html-1` 是旧文档兼容合同，其原有有限 CSS 集合还允许非负间距、边框、字重及受控主题颜色。这个历史能力不适用于新作者输入；迁移须显式重新编译核对，不能仅把 profile 字符串改为 2。

两个 profile 都拒绝全局规则、导入、资源 URL、脚本表达式、位置覆盖、变换、隐藏内容、重排顺序、字体大小/字体族与不受支持的声明。选择器只可由允许标签、局部 class、通配符和普通组合符组成，经程序改写 class 并加作用域；不接纳全局 ID、伪类、伪元素和属性选择器。各属性/值的实际允许集合由实现及负例测试固定，不能静默忽略不支持的声明。

无效 HTML、属性、CSS 或结构必须显示诊断；不悄悄删去重要内容后当作成功。原数据和可用的原图/原页继续保留。

## 统一排版

基础字号、字体、主题、外层宽度和展开仍由阅读器拥有。HTML 块继承用户字号；不通过缩小字号、整体缩放或隐藏列挤进版心。表格使用真实语义 table，文字换行、数值/短数学原子不拆坏。超宽区域只在对象内部横向滚动，最后一列和全部行均可达；长表沿文章自然向下展开。

局部布局可以记录必要的分组、相对列关系、对齐和结构间距。代码中不得出现按文章 ID、表号或标题选择的渲染补丁。具有实际意义的标签写入 HTML，不仅存在于 CSS 生成内容；复制与阅读顺序须与 DOM 一致。支持哪些安排与选用方式见 [模块与布局](内容模块与布局.md)，可组合范例见 [范例索引](../services/workspace/authoring-examples/index.md)。

当前对象原位向右展开：保留前后正文和目录，临时隐藏覆盖范围内的批注，收起恢复；图片、标准表格和 HTML 对象可独立调宽及重置。用户还可为对象设置独立字号，默认跟随正文；这些查看偏好由服务保存，不创建正文 revision。语义 DOM、引用和正在编辑的草稿保持不变，具体行为见 [阅读器页面设计](阅读器页面设计.md)。原页定位按 [PDF 双向同步](阅读与PDF双向同步.md) 的当前合同执行，不能从一个对象的存在推定有可靠的 PDF 区域。独立公式使用 `math` 块，不属于本页 HTML 图表展开能力。

## 文本视图、双语和来源指纹

程序解析每种语言 HTML，生成内部树、节点索引和每个节点的文本视图。文本视图使用解码后的 Unicode 文本；普通 HTML 文本的 ASCII 空白折叠为空格，pre 内保留原文，br 和块内结构分隔用换行。数学原子在文本视图中表示为 `$` + 原 TeX + `$`。粗体、斜体等保留语义元素，但不把 HTML 标签或 Markdown 强调符号计入文字偏移。所有字符偏移按 UTF-16 code units 计算，与现有浏览器选区一致。

每个文字片段记录它在该节点文本视图中的起止偏移；公式是不可拆的片段。引用记录 `document_id + revision + block_id + variant + field:"html_text" + node_id`，再记录范围、quote 和必要上下文。原型内部对象可使用 `documentId/blockId/nodeId`，对外工具合同按上述字段映射。跨节点的引用须明确多个目标，不能把多个格伪装成单节点连续范围；早期小样的单节点选区范围见其独立验证记录。

源/译结构一致且节点 ID 对应时，可以在同一格或段内显示上下对照；结构不同则使用整块上下对照。只有译文指纹匹配且节点的文本与语义内容相同时才共享显示一次；共享 DOM 保留源/译两个地址，对照模式的新引用默认原文，译文模式使用译文地址。缺译或待核对状态不因文字相同消失。

HTML 译文的指纹输入是 `[L, "html", html_profile, semantic_tree]`，沿用 [双语对照](双语对照.md) 的紧凑 JSON、UTF-8、SHA-256 规则。semantic_tree 按解析后的节点顺序构造：元素为 `[tag, 按名称排序的语义属性键值数组, children]`，文字为规范化字符串，数学节点保留 `data-tex`。局部 class 和 CSS 不进入指纹；节点 ID、内容、结构、跨度、表头、资源和语言进入。相同解析规范下计算；版本变化不能静默刷新旧指纹。

纯 CSS 修改仍递增正文 revision 以绑定构建结果，但不令译文过期。原文或结构修改后保留旧译文并标记待核对。作者原有双语内容仍属来源内容，不自动归类为生成译文。

## 旧引用和修订

迁移表格时保留块 ID；内部节点 ID 一次分配后持久保存。`reference_mappings` 每项记录 `from_revision`、`variant`、旧 `field`、必要的旧 `row/column`、新 `node_id`、`kind` 与 `previous_text`。`kind` 可为 `exact`、`merged` 或 `reformatted`。previous_text 是供核对的历史字符串，不能作为新正文编辑。覆盖空槽位没有可证明目标时不编造映射。

解析旧引用先检查版本、旧地址及摘录与 previous_text 一致；完全相同的文本视图可直接沿用范围。强调标记或已核实换行改变时，只有新摘录能唯一对应才映射；否则保留原摘录并标记 unresolved。映射成功仍保存原地址、版本、范围与摘录快照；不能只改字段而丢掉历史依据。

MCP 读取 HTML、节点文本、身份及来源，修订 HTML 原文。保存使用 revision 冲突检查，经 HTML/CSS、资源、表格关系、翻译状态和引用检查后，原子保存正文与派生索引。索引不能独立编辑；失败保留上一成功版本。当前服务器保存与 MCP 修订已实现，具体入口和验证边界见 [服务说明](../services/workspace/README.md)；历史浏览器小样不代替服务验收，也不证明外部账号已经连接。

## 历史 Attention 表 3 小样的验收范围

这一小样保留 schema 1 的原文档与完整文章包，另存 schema 2 的 HTML 小样，仅替换同一 `S6.T3` 块并递增 revision。表格原文、中文翻译、来源页、20 行数据、13 列关系、跨行标签、七列说明、空值含义和强调均可核对。HTML/CSS 是样本内容，HtmlBlock 组件不包含 Attention 或表 3 的专用分支。它记录早期 HTML 集成验证，不是当前 Agent 提交的必选文档或布局模板。

必须检查：三种语言模式；原文/译文选区与保存；对照模式相同值共享但身份不丢；切换语言后回跳；重新加载后的本地会话引用；旧行列引用迁移；字号和容器变化后定位与最后一列可达；HTML/CSS 无效输入的诊断。实验会话与原示例会话分开，首次可复制原会话并在副本上验证迁移，不覆盖原记录。

每次变更均须记录实际样本、窗口尺寸、字号、展开与返回、双语选区、引用回跳、草稿及会话恢复的结果；不以 spec 的存在当作实现证明。
